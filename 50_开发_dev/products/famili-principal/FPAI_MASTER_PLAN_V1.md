# FPAI Master Plan V1

## Mission

Build `法咪莉校长` as an independent family-growth AI principal and long-horizon multimodal digital-human IP: warm, intellectually clear, practical, bounded, interactive, able to teach and converse, and grounded in source-traceable education methods rather than identity mimicry.

The destination is a Family-owned AI person, not a chatbot skin and not a cloned real person. Text intelligence is the foundation; voice, avatar, classroom-style teaching, and digital-human presentation are later layers that require separate authorization.

## Non-Negotiables

```text
METHOD_INHERITANCE = YES
IDENTITY_CLONING = NO
FAMILY_M2_DEPENDENCY = NONE
TRAINING_STARTED = NO
FP0 = PASS_INTERNAL
FP1 = AUTHORIZED_TEXT_INTELLIGENCE_MVP
MULTIMODAL_DIGITAL_HUMAN_IP = LONG_TERM_PRODUCT_DIRECTION
DH0 = AUTHORIZED_DIGITAL_HUMAN_IP_FOUNDATION
VOICE_AVATAR_DIGITAL_HUMAN_RUNTIME = NOT_AUTHORIZED_IN_DH0
DH0_EQUALS_FP3_RUNTIME = NO
DH1 = NOT_AUTHORIZED
```

- Bobo source material may inform method extraction only through lineage-preserving distillation.
- Bobo identity, voice, likeness, and personal persona must not be cloned.
- Corpus rights are never inferred from file names, repo location, or prior usage.
- FPAI outputs are hypotheses, suggestions, scripts, or action cards, not facts, diagnoses, Family core state, or Named Actions.
- High-risk family scenes require human gate.
- DH0 creates a new Family-owned digital-human IP; it must not clone a real person's face, voice, identity, endorsement, or private persona.
- DH0 is the digital-human IP design system and prototype acceptance standard. It is not voice/avatar/digital-human runtime.

## DH0 Deliverables

1. Digital-human IP Bible.
2. Visual direction and static concept exploration.
3. Non-cloned voice direction and speaking style brief.
4. Multimodal experience map across text, voice, avatar, micro lesson, and companion surfaces.
5. Prototype acceptance criteria for future voice/avatar implementation.
6. Asset rights and provenance system for future production candidates.

Required modality layering:

```text
Principal Soul
  -> Principal Intelligence
  -> Structured Response
  -> Presentation Adapter
  -> Text / Voice / Avatar
```

The avatar or voice layer must not own a separate persona, prompt, safety policy, or memory continuity model.
