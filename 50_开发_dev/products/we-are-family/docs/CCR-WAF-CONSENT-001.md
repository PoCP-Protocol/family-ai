# CCR-WAF-CONSENT-001

Status: PROPOSED_RULING
Date: 2026-08-10

## Question

Should We are Famili introduce a product-local `COMMUNITY` consent purpose for WF1 challenge participation?

## Ruling

Do not add `COMMUNITY` to the central consent vocabulary for WF1.

Use the existing central purposes:

| WAF scenario | Consent purpose |
| --- | --- |
| Challenge participation | `SERVICE` |
| Recording a WAF participation into Family growth history | `GROWTH_TRACKING` |
| FPAI reads minimum necessary Family context | `AI_PERSONALIZATION` |
| Public family story publication | `CONTENT_PUBLICATION` |
| Model training or model improvement | `MODEL_IMPROVEMENT` |

## Constraints

- Consent is central, not product-local storage.
- WAF must not invent its own consent vocabulary.
- WAF participation remains community state until a user-confirmed Named Action bridges it into Growth OS.
