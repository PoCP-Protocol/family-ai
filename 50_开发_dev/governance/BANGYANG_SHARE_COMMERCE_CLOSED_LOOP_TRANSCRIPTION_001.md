# 分享裂变商城组：业务场景闭环逐字转录 001

> **视觉来源：** PPT 第 8 页下方闭环条与设计/经营重点条。
> **箭头语义：** 节点按左到右连续推进。此处仅记录用户提供 PPT 的设计逻辑；不构成真实支付、会员、拼团、外发、交易或商业化能力授权。

## UI 页到闭环节点

| 顺序 | 上方 UI 标题 | 下方闭环节点 | 原文说明 | 输入 → 输出 |
|---:|---|---|---|---|
| 1 | 裂变商城首页 | 免费测评入口 | 吸引家长参与 | 首页入口 → 家长参与 |
| 2 | 商品详情 | 生成成长报告 | 提供个性化建议 | 参与信息 → 成长报告 |
| 3 | 邀请有礼 | 分享给家长好友 | 邀请获得奖励 | 报告/权益 → 分享动作 |
| 4 | 拼团专区 | 好友领取测评 / 参团 | 参与测评或加入拼团 | 好友分享 → 测评或参团状态 |
| 5 | 积分商城 / 任务中心 | 购买课程 / 服务 / 好物 | 完成下单成交 | 任务/选择 → 购买意向/交易节点 |
| 6 | 我的收益 / 会员中心 | 复购与会员升级 | 持续成长与复购 | 服务历程 → 会员关系 |

## 原图“设计与经营重点”逐字转录

| 区块 | 原文内容 |
|---|---|
| 家长分享动机 | 帮朋友解决教育问题 + 获得成长权益 |
| 商城 SKU 建议 | 测评卡 / 挑战营 / 陪跑服务 / 工具包 / 会员卡 |
| 奖励设计 | 积分、优惠券、会员权益、顾问服务券 |
| 风控原则 | 弱化现金分销；强化成长价值与转介绍 |
| 目标 | 让分享变成获客；让商城变成转化与复购中心 |
