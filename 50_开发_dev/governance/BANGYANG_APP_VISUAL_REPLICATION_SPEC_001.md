## 2. 色板与色彩角色

## 3. 移动页面框架

| 区域 | 固定规格 | 复刻要求 |
|---|---|---|
| 顶部栏 | 白色、约 44–56 px、返回箭头/标题/更多菜单或分享图标 | 结构简洁，不加侧栏、面包屑或桌面工具栏。 |
| 内容区 | 冷白底、左右约 12–16 px 边距、纵向卡片流 | 信息密度高但模块清晰，卡片间距约 8–12 px。 |
| 卡片 | 白底、12–16 px 圆角、细灰蓝边线或极轻阴影 | 不使用大面积玻璃拟态、粗边框或宽桌面版留白。 |
| 主 Hero | 亮蓝/深蓝渐变、亲子/儿童/机器人插画、大号白字、圆角 | 按截图分别承载体检、任务、邀请、积分、海报和商品。 |
| 底部动作 | 满宽圆角蓝按钮或蓝/橙双按钮 | 固定在内容底部或安全区上方，避免通用弹窗式交互。 |
| 底部导航 | 四栏 tab bar：图标在上、文字在下、当前蓝色高亮 | 保持小程序式比例和选中态，不改造成悬浮 SaaS 导航。 |

## 4. 模块复刻库

| 模块 | 来自页面 | 组成 | 动效节奏 |
|---|---|---|---|
| 体检 Hero | 体检入口 | 蓝渐变、亲子插画、步骤指示、主按钮 | 插画可轻微漂浮，按钮按压反馈。 |
| 雷达报告 | 体检报告 | 中心六边/雷达图、数值标签、三色提示行、7/30/90 路径 | 数值/线条入场，不增加独立仪表盘语法。 |
| 任务清单 | 每日任务 | 编号圆点、标题、奖励/时长、勾选框、进度条 | 勾选和进度条温和过渡。 |
| 孩子成长卡 | 孩子助手 | 儿童插画、能量条、2×2 彩色卡、挑战/奖章 | 卡片微浮动和能量条增长。 |
| 榜单 | 排行榜 | 顶部筛选、前三领奖台、列表、本人排名卡、徽章 | 皇冠/奖杯轻微出现，不加高噪动画。 |
| 海报 | 分享报告 | 纵向蓝色画布、儿童资料、故事标题、数据卡、徽章、二维码 | 海报自上而下渐显。 |
| 商城商品卡 | 商城首页/拼团 | 商品图、标题、价格、人数、头像叠放、行动按钮 | 列表入场与按钮按压。 |
| 邀请进度 | 邀请有礼 | 数字进度、三步节点、奖励四宫格、二维码 | 节点依次点亮。 |
| 积分中心 | 积分商城 | 亮蓝积分大卡、任务列表、兑换网格 | 数字轻计数，金币/奖杯轻微浮动。 |
| 会员中心 | 我的 | 资料卡、数据四列、服务列表、深色会员横幅 | 皇冠/会员卡轻微上浮。 |

## 5. 图标与排版

图标沿用截图中的高饱和、扁平、圆润彩色小图标；不使用细线条 SaaS 图标或大号技术符号。中文标题使用黑蓝加粗，正文为灰蓝，标签和辅助信息使用小号字。标题、插画、主按钮和数据是每屏四个主要视觉焦点；页面不展示环境、开发、测试、策略、模型、治理、审计或其他内部术语。

## 6. 复刻验收

每一页必须核验：顶栏结构、Hero 色彩/插画区、卡片顺序、圆角与间距、按钮形态、彩色图标角色、底部导航、动效强度、用户可见文字。每页截图与原图对照后，任何明显的页面框架、颜色角色、卡片比例或导航形态偏离都应优先修正。
