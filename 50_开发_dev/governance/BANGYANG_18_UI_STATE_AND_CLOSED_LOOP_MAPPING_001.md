## 跨闭环状态关系

1. **入口状态**：核心服务首页/体检入口/商城首页均承载低门槛引导，但原材料对应不同闭环。复刻时保持视觉分别独立，不能因相似而混页。
2. **报告状态**：核心报告、增长报告、成果海报分别对应“解释”“成长路径”“展示分享”；不得将它们的语义混成同一个真实评分结果。
3. **执行状态**：个性化方案、每日任务、陪跑社群、孩子端分别承担计划、行动、陪伴和参与；其原图上的数字只可作为静态/合成页面内容。
4. **关系状态**：邀请、拼团、积分、会员是商城闭环的关系/交易设计；本轮仅能复刻页面与模拟导航，不能接入真实商业动作。
5. **回流状态**：任务完成 → 完成度/计划；荣誉 → 个人空间；报告/海报 → 分享；邀请/商品 → 商城/会员。当前回流只能是内部 UI 导航和受控合成状态。
