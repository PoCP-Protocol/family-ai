## 页面—流程执行次序

```
首页
  → 家庭成长体检
  → 成长报告
  → 为你准备的成长路径（贝壳式分配）
  → 21 天/90 天成长计划
  → 每日任务 / 孩子成长 / 成长课堂
  → 服务、活动、社区
  → 成长记录 / 海报 / 邀请
  → 商城、积分、会员、我的家庭账户
```

## 贝壳式分配的固定 UI 规格

贝壳式分配不得单独显示为“分配机制”或技术能力。它必须复刻为原图中的白色圆角横向/网格卡片：使用蓝色标题、彩色扁平图标、浅蓝分区、简短成长场景说明和单个亮蓝按钮。卡类型只限于原始材料已有的课程、每日任务、亲子工具、成长活动、陪伴服务和会员权益。页面可见名称统一为“为你准备”“下一步成长路径”“今天可以继续”，不出现算法、模型、分配、推荐排序或内部术语。

## 固定禁止偏离

不得因贝壳式分配而替换体检、报告、计划、任务、内容、孩子端、榜单、海报、商城、积分、会员、服务、社区或我的家庭账户页面。不得将 App 改为桌面式后台、技术助手、通用咨询页或独立聊天窗口。不得在 UI 暴露开发、模型、治理、测试和内部状态。
