## 原图路由原则

1. 任一页面的可见文字、人物、图标、照片、卡片、数值和状态均以相应清晰原图为准。
2. DOM 上的透明热点只允许改变 DEV 内部 `page` 状态；不得发送网络请求、上传材料、写入跨家庭数据或调用外部模型。
3. 每页验收仍需完成：原图登记、逐元素规格、路由接入、同宽高浏览器截图、可见差异清单与修正。未关闭差异时统一为 `NOT_MATCHED`。
