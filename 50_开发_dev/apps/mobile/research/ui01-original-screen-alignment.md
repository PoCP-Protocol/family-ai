## 本轮对齐状态

已通过本机 Expo Web 入口捕获当前 UI-01 运行画面。以下项目均为对原始画面可见元素与当前画面可见元素的直接对照，不是产品推测。

| 原始基线中的可见元素 | 当前实现中的对应状态 | 差异结论 |
|---|---|---|
| 顶部“家庭成长平台”、更多入口、圆形入口、早安/陪伴问候与通知 | “我们家的今天”、晚间问候、单一“家”标记 | 顶部信息架构与时间问候不同。 |
| 免费家庭测评大横幅，包含家庭插画、3分钟说明与“立即测评”行动 | 深蓝“今晚一件事”行动卡 | 首屏主视觉与首要行动不同；当前测评仅在下方快捷卡。 |
| 六项快捷功能：AI诊断、21天挑战营、90天成长计划、成长案例、专家直播、家庭顾问 | 三项成长旅程快捷入口：成长营、家庭测评、名师专区 | 功能入口数量、名称、排列和出口均不一致。 |
| 今日成长任务：三条任务、完成状态、去完成和“查看全部” | 单一今日行动卡 | 任务列表、逐项状态与查看全部出口缺失。 |
| 推荐内容/服务横向卡片与“更多”入口 | 未显示推荐卡片模块 | 原始模块未实现。 |
| 四项底部导航：首页、计划、社群、我的 | 五项底部导航：今天、成长、发现、服务、我的 | 一级导航结构不同。 |

当前画面保留了原始基线没有显式展示的“建议来源清晰”和 21 天成长营进度条；这两项属于当前实现新增模块，不能在未确认前视为原图替代物。

因此，UI-01 当前**不满足逐画面严格对齐**。下一步将只对原始画面的六个明确模块补建“元素—功能点—数据状态—跳转出口”清单，并在用户确认采用原图首页信息架构后实施，不自行将当前深蓝行动卡、五标签导航或新增模块当作等价替代。

## 原始功能热区与当前实现对照

原始 Web 静态实现对首页热区标注了下列真实目标：免费家庭测评 → `assessment`；AI诊断 → `ai-report`；21天挑战营 → `growth-camp-21`；90天成长计划 → `core-plan`；成长案例 → `poster`；专家直播/家庭顾问 → `teacher-zone`；今日成长任务及三条任务 → `growth-daily-task`；三张推荐卡 → `commerce-mall`；底部导航 → `home`、`plan`、`core-community`、`core-mine`。

| 原始功能点 | 原始目标 | 当前 UI-01 状态 |

| 21天挑战营 | `growth-camp-21` | 已有成长营入口，但位置和样式不同。 |

## 后续 UI 目标取证

原始 Web 的热区分发代码表明：三条今日任务均进入 `growth-daily-task`；成长案例进入 `poster`；专家直播与家庭顾问均进入 `teacher-zone`；推荐卡均进入 `commerce-mall`。结合当前 35 UI 注册表，采用以下目标映射：

| 原图热区 | 原始页面语义 | 当前目标 UI | 实施边界 |
|---|---|---|---|
| 免费家庭测评 | `assessment` | UI-02 | 首页只作入口。 |
| AI诊断 | `ai-report` | UI-03 | 首页只作入口。 |
| 21天挑战营 | `growth-camp-21` | UI-35 | 首页只作入口和进度摘要。 |
| 90天成长计划 | `core-plan` | UI-04 | 首页只作入口。 |
| 成长案例 | `poster` / `growth-poster` | UI-12 | 首页只作入口。 |
| 专家直播、家庭顾问 | `teacher-zone` | UI-19 | 首页只作入口；直播关注回执由服务页处理。 |
| 三条今日任务 | `growth-daily-task` | UI-09 | 首页只显示任务清单和状态，所有任务热区进入统一任务页。 |
| 推荐内容/产品及更多 | `commerce-mall` | UI-13 | 首页只显示横向推荐卡，商品详情和意向由 UI-13/14 处理。 |

该映射以原始分发代码与现有 35 UI 注册表为依据。当前五标签导航与原图四标签导航仍是独立架构差异，未获得用户确认前不改变。

## 高分辨率视觉参考

高分辨率原图确认：测评 Banner 使用明亮蓝色渐变、左侧三行白字和白色胶囊按钮、右侧四口家庭插画；六项入口为两行三列、白底且图标以青蓝/橙/绿/浅蓝/红橙分组；任务为三行紧凑白色清单；推荐内容/服务为三张横向等宽内容卡；底部为四等分导航。该参考图在本轮仅用于 UI-01 的结构、比例和视觉内容对照，不裁剪或伪装为当前可交互页面。
