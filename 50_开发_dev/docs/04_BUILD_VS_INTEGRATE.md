# Build vs Integrate

## Family Core：必须自主开发

- Family ID
- Parent / Child / Relationship
- LifeStage
- Consent domain
- GrowthProfile
- GrowthPriority
- Journey
- Intervention
- GrowthAction
- GrowthEvent
- Perspective
- Evidence
- Milestone
- Outcome
- Timeline

## AI差异化能力：自主编排

- Model Gateway
- Agent Contracts
- Decision Contracts
- Knowledge Foundry domain
- Evaluation
- Causal Data Model

## Commodity：集成优先

- CRM
- LMS / 教务
- Order
- Payment
- Live Streaming
- SMS
- Basic IM
- Invoice
- CDN / File

原则：
不要为了“统一平台”重复建设成熟Commodity能力。
