# M2 Vertical Slice Delivery Standard

每个 M2 Wave 必须同时交付：

1. User Journey
2. Domain Contract
3. Data Contract
4. API Contract
5. Frontend
6. AI（需要时）
7. Consent / Safety
8. Unit / Integration / HTTP E2E
9. Demo Scenario
10. Product Metric
11. Outcome Link

以下不算Done：

- 只有后端API
- 只有数据库表
- 只有UI Mock
- 只有Prompt
- 只有AI Demo
- 只有测试
- 只有文档

Wave Done：

REAL USER CAN DO SOMETHING
+
SYSTEM RECORDS IT
+
SYSTEM CAN SHOW/EXPLAIN THE RESULT
