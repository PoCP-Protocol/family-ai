# L0「选择你现在需要的支持」UX / Gate 草案 001

> **状态：`DRAFT_FOR_ASSESSMENT_APP_GATE_DECISION_INPUT`。**
>
> **性质：** 这是一份 App/小程序体验与治理草案，不是问卷运行时、设计稿实现、API 契约、数据库模型或业务代码授权。
>
> **目标：** 让可信家庭中的监护人表达“此刻想获得哪类支持”，由 Family 只展示当前已准入的候选，并由家庭决定是否继续或 `NO_ACTION`。不测量孩子，不给家庭打分，不作诊断。

## 1. L0 产品承诺

> **“我们不会给孩子或家庭打分。你可以说说现在想先理清什么；平台只会展示当前安全且已准入的支持方式，是否继续由你的家庭决定。”**

L0 不是“免费家庭测评”“AI 成长诊断”或“生成最佳方案”。它是一个低压力入口，帮助家庭生成或补充现有 `Need → Intent → 家庭明确 Decision / NO_ACTION` 服务过程。

## 2. 体验总则

| 原则 | UX 要求 |
|---|---|
| 可自主 | 每页始终有“暂不继续”“返回”“退出”路径；退出不影响家庭的基础功能或资格。 |
| 无结论 | 页面不显示分数、等级、雷达图、颜色风险、高低比较、人格/能力词或“最佳”推荐。 |
| 家庭决定 | 任何候选之后必须由家庭主动选择；候选展示不自动创建 Plan/Case。 |
| 最小数据 | 只收集当前服务目的必要的 Need、Intent 和家庭决定；不引入标准化工具题项或儿童直接作答。 |
| 可理解 | 先解释“为什么问、不会怎么用、如何撤回”，再要求任何输入。 |
| 文本优先 | 所有内容可在纯文本、低带宽、屏幕阅读器、无图像/无动效/无模型环境下完成。 |
| 安全停止 | 高风险、诊断、危机、真人服务、外部资源、第三方数据、儿童直接作答触发 Human Gate 或 fail-closed。 |

## 3. 页面信息架构与逐页微文案

### 页面 0：入口卡 / 选择开始

| 项目 | 设计内容 |
|---|---|
| 页面名称 | **选择你现在需要的支持** |
| 主文案 | “每个家庭都会有需要理清的时候。你可以用几分钟告诉我们此刻最想先获得哪类支持。” |
| 边界提示 | “这不是测评、评分或诊断。我们不会根据你的回答给孩子或家庭贴标签。” |
| 主按钮 | `开始确认` |
| 次按钮 | `暂不需要` |
| 链接 | `了解数据如何使用` / `退出` |
| 为什么问 | “为了让你自己决定是否查看与当前需要有关的、已准入的支持方式。” |
| 不会怎么用 | “不会用于计算成长分、家庭排名、公开画像、商业推送或训练模型。” |
| 如何撤回 | “开始后你可以随时退出；若已保存服务记录，可在家庭数据与同意设置中撤回服务用途。” |
| 事件上限 | 无；点“开始确认”只进入下一页面，尚不写入 Need。 |

### 页面 1：当下需要

| 项目 | 设计内容 |
|---|---|
| 页面名称 | **你现在最想先理清什么？** |
| 辅助文案 | “可以写一句话，也可以直接跳过。请不要填写需要立即处理的危机信息或他人的隐私。” |
| 输入方式 | 可选短文本框；仅允许当前家庭监护人输入。 |
| 示例占位符 | “例如：最近和孩子沟通时容易着急，想先找到一个更平和的开始方式。” |
| 主按钮 | `继续` |
| 次按钮 | `跳过这一步` / `返回` / `退出` |
| 为什么问 | “让家庭用自己的语言说明本次服务想围绕什么展开。” |
| 不会怎么用 | “不会自动判断原因、心理状态、能力或风险；不会生成诊断或成长结论。” |
| 如何撤回 | “继续前可清空；保存后可撤回服务用途，系统停止复用本次内容。” |
| 候选事件上限 | 仅在家庭点击 `继续` 后可创建一个 Need；空输入进入支持偏好页时不得自动虚构 Need。 |

### 页面 2：支持偏好确认

| 项目 | 设计内容 |
|---|---|
| 页面名称 | **你希望先获得哪类支持？** |
| 选择项（候选） | `亲子沟通`、`日常节奏`、`学习安排`、`先不选择方向`。 |
| 选择项说明 | 每项只表示“本次希望先看的支持方向”，不表示孩子/家庭的问题或能力。 |
| 主按钮 | `查看当前可选支持` |
| 次按钮 | `我想暂不行动` / `返回` / `退出` |
| 为什么问 | “帮助家庭决定本次是否要查看某一类支持。” |
| 不会怎么用 | “不代表系统判定这是最重要的问题；不会生成长期偏好标签或跨家庭比较。” |
| 如何撤回 | “在家庭决定前可以改选、跳过或退出；后续可暂停服务过程。” |
| 候选事件上限 | 家庭明确选择后可创建/确认 Intent；选择“我想暂不行动”只能走 `NO_ACTION`，不得创建 Intent、Plan 或 Case。 |

### 页面 3：候选说明 / 无候选状态

| 项目 | 有合格候选时 | 无合格候选或资格不足时 |
|---|---|---|
| 页面名称 | **当前可以查看的支持方式** | **当前没有可安全提供的下一步** |
| 主文案 | “以下内容已通过当前服务范围的准入检查。是否继续由你的家庭决定。” | “平台不会用未经确认的内容、服务或自动判断来替代。” |
| 每个候选卡 | 来源/内容类型、适用限制、风险/准入摘要、`查看说明` | 不展示伪候选、付费引导、真人服务承诺或外部链接。 |
| 主按钮 | `选择一个下一步` | `保留本次需要` |
| 次按钮 | `暂不行动` / `返回` / `退出` | `暂不行动` / `返回` / `退出` |
| 为什么问 | “只让家庭看见当前已准入的选择，而非“最佳方案”。” | “说明为什么当前系统必须停止，而不是假装能给出答案。” |
| 不会怎么用 | “候选不是效果承诺；选择也不代表必须执行。” | “无候选不代表家庭没有需要或孩子/家庭存在问题。” |
| 如何撤回 | “不选即可；已选后可在下一页再次确认或暂停。” | “可退出，或只保留家庭表达的需要。” |
| 候选事件上限 | 读取 admitted Resource candidates；不得在展示时写 Decision/Plan/Case。 | 无资源时不可降级展示未准入资源。 |

### 页面 4：家庭决定

| 项目 | 设计内容 |
|---|---|
| 页面名称 | **这一步由你的家庭决定** |
| 主文案 | “你可以选择继续、暂不行动，或回到上一步。开始后也可以暂停。” |
| 选择项 | `选择这个下一步` / `暂不行动` / `返回看看其他选择` |
| 确认提示 | “选择后，平台只会建立本次服务过程的记录；它不代表孩子已经改善，也不承诺结果。” |
| 为什么问 | “避免系统替家庭做决定，也避免候选展示被误写为已执行服务。” |
| 不会怎么用 | “不会自动开始任务、扣费、预约真人、发送外部信息或创建公开档案。” |
| 如何撤回 | “选择前可随时返回；选择后可按服务流程暂停，或撤回服务用途。” |
| 候选事件上限 | `ACCEPT` 只能在资源 admitted 且 T2 合格时写入 Decision 并创建 Plan/Case；`NO_ACTION` 只能通过显式 `DISMISS` + 空选择写入，不创建 Plan/Case。 |

### 页面 5：下一步 / 安全等待 / 主观回看

| 状态 | 微文案 | 系统上限 |
|---|---|---|
| 已开始声明性服务过程 | “这是你们家庭选择的下一步。你可以按自己的节奏继续、暂停或退出。” | 只显示 Plan/Case 事实和可选 FollowUp。 |
| 主观回看 | “这一步对你们是否有帮助？这只记录家庭感受，不是成长结论。” | 只写 FollowUp 主观信号；不写效果、分数或标签。 |
| REVIEW/HIGH_RISK | “当前请求正在按安全边界处理。平台没有作出自动判断、服务承诺或外部转发。” | durable handoff 状态；无真人身份、预约或时限承诺。 |
| NO_ACTION | “你选择了暂不行动。此选择不会创建计划或服务过程。” | 仅 Decision/审计事实，无 Plan/Case。 |

## 4. 页面状态与写入上限

| 用户动作 | 允许的候选领域状态 | 明确禁止的状态 |
|---|---|---|
| 打开入口/阅读说明 | 无 | session 之外的行为追踪、画像或营销标记。 |
| 输入当下需要并继续 | Need | 评分、问题标签、自动 Intent/Plan/Case。 |
| 选择支持方向 | Intent | 风险等级、最佳方案、儿童标签。 |
| 看候选 | 只读候选 | 自动 Decision、自动订阅、自动任务。 |
| 明确接受合格候选 | Decision；满足 T2 后才可 Plan/Case | 自动扣费、真人预约、外部资源推送、结果记录。 |
| 选择暂不行动 | 显式 NO_ACTION Decision | Intent、Plan、Case、任务、提醒。 |
| 自愿回看 | FollowUp（主观感受） | 成长 outcome、模型训练样本、长期标签。 |

## 5. 文本等价路径

1. 所有页面有语义化标题、说明、问题、按钮、状态和退出链接。
2. 不用儿童头像、雷达图、色块、进度环、动效、语音或视频表达必须理解的信息。
3. 任何图标/插画必须有等价文字；任何颜色状态必须有文字状态。
4. 输入仅要求文字/结构化选择；不要求上传照片、音频、视频、学校报告、定位、通讯录或第三方数据。
5. 若浏览器/设备不支持视觉组件，仍可按“说明 → 需要 → 偏好 → 候选/无候选 → 家庭决定/NO_ACTION → 回看”完成。

## 6. 禁止文案与替代文案

| 禁止文案 | 合规替代 |
|---|---|
| 免费家庭测评 | 选择你现在需要的支持。 |
| 3 分钟测出孩子成长状态 | 用几分钟确认此刻希望先获得哪类支持。 |
| AI 精准诊断 / AI 成长报告 | 平台不会作诊断；只会根据你的确认显示当前已准入的选择。 |
| 你的孩子沟通能力不足 | 你们家庭希望先从亲子沟通支持开始吗？ |
| 为你推荐最佳方案 | 展示当前已准入候选，由你的家庭决定是否继续。 |
| 完成即得成长积分/会员权益 | 你可以跳过、暂停或退出；回答不会决定你的家庭价值或资格。 |
| 立即预约专家/班主任 | 当前没有自动真人服务；如未来开放，将先说明接收方、目的和同意边界。 |
| 你已成长 78 分 | 本次服务过程摘要（不代表成长结论）。 |

## 7. 验收负例

| 编号 | 负例 | 必须的行为 |
|---|---|---|
| UX-L0-01 | 无可信 Account / ACTIVE binding / membership | 不进入 L0，不显示家庭内容。 |
| UX-L0-02 | 账户 disabled 或 context ambiguous | fail-closed；不默认选择家庭成员。 |
| UX-L0-03 | 无 SERVICE consent 或已撤回 | 不创建/复用 Need、Intent、候选或过程摘要。 |
| UX-L0-04 | 输入含诊断、危机、第三方、真人服务或外部资源请求 | 不作自动判断、不外发；进入安全停止/Human Gate 文案。 |
| UX-L0-05 | 空 Need 直接点击继续 | 不虚构 Need；只允许跳过或返回。 |
| UX-L0-06 | 家庭选“暂不行动” | 只允许 NO_ACTION；零 Plan、零 Case、零任务。 |
| UX-L0-07 | 未准入/降级/无 executor 的资源 | 不可见或不可选；不以“推荐”兜底。 |
| UX-L0-08 | 资源候选展示后未明确决定 | 零 Decision、零 Plan、零 Case。 |
| UX-L0-09 | 同一写入幂等键重放或不同内容冲突 | 重放零重复；冲突返回明确错误。 |
| UX-L0-10 | 尝试显示分数、雷达图、标签、排行、成长结论 | 构建/审计失败；该 UI 不可进入候选版本。 |
| UX-L0-11 | 图片/动效/模型不可用 | 纯文本路径仍可完成或安全退出。 |
| UX-L0-12 | 尝试将 FollowUp 转化为效果/营销/模型数据 | 拒绝；只保留家庭主观服务感受。 |

## 8. 独立 App Gate 必问问题

1. 是否批准 L0 进入独立任务契约设计，且前台统一命名为“选择你现在需要的支持”或“确认当下需要与服务偏好”？
2. 是否确认 L0 只复用既有 `Need → Intent → admitted Resource → Decision / NO_ACTION → Plan/Case → FollowUp`，并明确允许/禁止的最小页面与字段？
3. 是否确认 L0 的第一版本零分数、零标准化量表、零 AI、零儿童直接作答、零任务/积分、零真人服务、零外部资源、零商业化？
4. 是否确认 L0 每一步必须同时提供跳过、返回、退出或 NO_ACTION，并不会因跳过影响基本支持？
5. 是否确认高风险、诊断、危机、第三方、真人服务、外部资源和儿童直接作答全部转 Human Gate 或 fail-closed？
6. 是否确认候选文案只能写“当前已准入候选，由家庭决定是否继续”，禁止“最佳方案”“精准推荐”“效果承诺”？
7. 是否确认实施前还需分别裁决页面范围、API/DTO/DB 影响、移动视口/文本等价、真实 DB/E2E 矩阵和退出条件？
8. 是否确认 PR36 保持 Draft / AUTO_MERGE=NO / master=HOLD，L0 草案不构成任何 runtime 开发授权？
