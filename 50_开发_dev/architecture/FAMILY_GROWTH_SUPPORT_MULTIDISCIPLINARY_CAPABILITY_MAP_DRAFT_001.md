# 家庭成长支持多学科服务能力地图
## Family Growth Support Multidisciplinary Capability Map（草案 001）

> **状态：`DRAFT_FOR_ARCHITECTURE_AND_GATE_DECISION_INPUT`。**
>
> 本文是“服务能力地图”，不是儿童、家长或家庭的分类体系。它不能用于给某家庭归型、给某孩子定能力等级、给家长定压力等级，亦不能演化为分数、雷达图、权重模型、成熟度等级、自动推荐排序、跨家庭比较或训练模型。

## 1. 共同结构与不可越界原则

每个能力域只回答：Family 在该领域能帮助家庭表达什么服务需要、当前可以展示什么已准入支持，以及未来专业能力需要满足什么准入条件。

| 共同控制 | 统一要求 |
|---|---|
| 输入来源 | L0/L1 只接受可信家庭监护人的自愿文本化需要、偏好或决定；不接收儿童直接作答、第三方资料、外部工具结果、视频/音频或自动推断。 |
| 允许状态上限 | 仅 `Need`、`Intent`、已准入候选、`Decision` 或 `NO_ACTION`，以及既有服务过程的 Plan/Case/主观 FollowUp；无能力分、风险、诊断、画像、成长结论。 |
| 文本等价 | 任何入口、候选、解释、退出与安全停止均能以纯文本完成；不依赖图像、动画、语音、视频、多模态或模型。 |
| 家庭决定 | 平台只展示当前已准入候选；只有家庭明确决定才允许沿既有 T2 路径继续。 |
| 共同禁止 | 不做评分、分层、排名、比较、预测、AI 诊断、心理/临床结论、长期标签、公开画像、支付/会员定价、增长裂变或训练。 |
| 共同失败关闭 | 身份/家庭范围/有效 consent 缺失或撤回、资源不准入、资格不完整、专业责任缺失、文本路径不可用时，停止流程或允许 `NO_ACTION`。 |

## 2. 能力域总览

| 编号 | 服务能力域 | 领域真正服务的问题 | 当前最高可触达层 | 未来专业门槛 |
|---|---|---|---|---|
| D1 | 家庭需要与服务规划 | 家庭此刻希望获得哪类支持？ | L0/L1 | 无需标准化工具；若引入专业评估方法则转 L2 Gate。 |
| D2 | 共同决策与支持目标 | 家庭愿意先选择哪一步，或暂不行动？ | L1 | 专业共同决策、医疗/教育选择或真人协作需 Human Gate。 |
| D3 | 亲子沟通与关系支持 | 家庭是否希望探索沟通、关系或协作支持？ | L0/L1 | 专业观察、咨询或外部服务转 L2/独立服务 Gate。 |
| D4 | 日常节奏与养育支持 | 家庭希望调整哪些日常支持安排？ | L0/L1 | 行为干预、家长训练或临床支持转专业 Gate。 |
| D5 | 学习与发展支持 | 家庭是否希望了解进一步支持路径？ | L0/L1 仅偏好确认 | 标准化发展筛查、评估、解释、转介均为 L2 HOLD。 |
| D6 | 社会情绪与行为支持 | 家庭是否希望先看合规的支持方向？ | L0/L1 仅偏好确认 | ASQ:SE-2、SDQ、PSC 等筛查、解释和转介均为 L2 HOLD。 |
| D7 | 家长压力与家庭福祉 | 家庭是否希望获得养育支持或更好的服务安排？ | L0/L1 仅偏好确认 | PSI/PSS 等工具、心理支持或高敏感处理均为 L2 HOLD。 |
| D8 | 亲子互动观察 | 是否需要受训人员观察互动并反馈？ | 无自动入口，仅说明边界 | NCAST-PCI、PICCOLO 等为 L2 HOLD。 |
| D9 | 家庭安全与危机 | 是否出现当前普通服务流程不能处理的情况？ | 只能安全停止 | 本地资源、人工责任、SOP、法务/伦理审查后才可能进入 L3。 |
| D10 | 工具与证据治理 | 某工具/方法能否进入 Family 的未来审查？ | 静态治理目录 | 任何工具接入均需独立许可、数据、Human 与 App Gate。 |

## 3. 分域治理索引

### D1｜家庭需要与服务规划

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 帮助监护人用自己的语言说明“此刻希望家庭获得什么支持”，例如希望理清沟通、日常安排或进一步了解服务方向。 |
| L0/L1 可做边界 | L0 可确认当下需要与服务偏好；L1 可确认家庭优先事项、继续、返回、暂停或 `NO_ACTION`。 |
| L2/L3 HOLD 条件 | 当方法要求标准化题库、系统性家庭功能评估、专业解释、风险筛查或第三方资料时，转 L2/L3 HOLD。 |
| 输入与状态上限 | 可信成人的自愿最小文本；仅形成 Need/Intent/Decision/NO_ACTION。 |
| 禁止事项 | 家庭问题清单、家庭质量分、需要强度、家庭类型、支持优先级排序或效果判断。 |
| Human Gate | 触及诊断、危机、真人服务、外部资源、第三方数据或未成年人直接作答即停止自动路径。 |
| fail-closed | 无可信家庭上下文、无有效 SERVICE consent、空输入被要求自动补全、资源无资格时，不路由或 `NO_ACTION`。 |
| 文本等价 | 纯文本问题、选项、跳过、返回、退出与“暂不行动”均可用。 |
| 未来 Gate 条件 | 若引入 FCCA、FANS/CANS 等方法/工具，须核验许可、版本、培训、解释责任、数据与退出条件。 |

### D2｜共同决策与支持目标

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 让家庭在已准入候选之间明确选择是否继续，并可设定一个可暂停、可修改的服务目标。 |
| L0/L1 可做边界 | L1 允许家庭确认“先做哪一步”或 `NO_ACTION`；平台不替家庭做选择。 |
| L2/L3 HOLD 条件 | 医疗、心理、特殊教育、跨机构/真人协作、合同承诺或涉及儿童直接参与的共同决策均需独立 Gate。 |
| 输入与状态上限 | 家庭明确偏好与选择；仅 Intent/Decision/NO_ACTION 和现有 Plan/Case 链。 |
| 禁止事项 | “最佳方案”“AI 最优建议”“家庭目标完成率”“连续打卡等级”或强制任务。 |
| Human Gate | 专业选择、外部服务、资源争议、监护人分歧、重大生活决定。 |
| fail-closed | 未明确决定、T2 不合格、资源降级、PRACTICE 无 executor 或 consent 撤回时，不建 Plan/Case。 |
| 文本等价 | 所有候选附文字说明、来源/准入摘要、继续/返回/暂不行动；没有卡片或图标也完整可用。 |
| 未来 Gate 条件 | 需要明确成人授权矩阵、决定可逆性、审计、争议处理与实际服务交付责任。 |

### D3｜亲子沟通与关系支持

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 为希望改善日常沟通或亲子协作的家庭，提供可表达的服务方向和已准入候选入口。 |
| L0/L1 可做边界 | 家庭可表达“希望先看看沟通支持”，并决定是否进入一个已准入候选。 |
| L2/L3 HOLD 条件 | 互动质量判断、家庭治疗、专业咨询、冲突/暴力识别、音视频分析或真人陪跑均不在当前范围。 |
| 输入与状态上限 | 成人服务偏好；Need/Intent/Decision/NO_ACTION。 |
| 禁止事项 | 沟通能力分、关系健康分、冲突风险、父母/孩子角色标签、内容自动解释。 |
| Human Gate | 家暴、控制、虐待、安全、高敏感冲突、真人咨询或第三方介入。 |
| fail-closed | 自由文本触及高风险或专业判断时不分析、不推荐、不外发；普通路径安全停止。 |
| 文本等价 | 以“你希望先获得哪种支持？”表述，不需情绪识别、语音或动画。 |
| 未来 Gate 条件 | 若引入互动观察或真人服务，需专业资格、许可、隐私、服务协议、风险升级和独立 Gate。 |

### D4｜日常节奏与养育支持

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 支持家庭表达希望获得关于日常安排、亲子协作或轻量行动的服务方向。 |
| L0/L1 可做边界 | 支持偏好确认、已准入内容/服务候选浏览、家庭决定、暂停/NO_ACTION。 |
| L2/L3 HOLD 条件 | 行为矫正、睡眠/饮食/健康干预、临床建议、强制打卡、真人教练或效果追踪。 |
| 输入与状态上限 | 家庭偏好和服务过程状态，不记录儿童表现/依从度分。 |
| 禁止事项 | 习惯分、执行力分、连续任务排行、孩子行为预测、营销型任务奖励。 |
| Human Gate | 涉及健康、营养、药物、伤害、安全、专业干预或外部服务。 |
| fail-closed | 资源无准入、当前不可执行、同意撤回或家庭选择 NO_ACTION 时不生成任务/Case。 |
| 文本等价 | 简洁文本候选、步骤说明、暂停/退出；不以动效和连续打卡驱动。 |
| 未来 Gate 条件 | 如引入任务/提醒能力，需任务边界、儿童参与、通知、压力风险、数据最小化和独立 App Gate。 |

### D5｜学习与发展支持

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 允许家庭表达想了解学习或发展支持方向，但不判断孩子是否落后、优秀或需要诊断。 |
| L0/L1 可做边界 | 家庭偏好确认、合规支持候选展示与家庭决定。 |
| L2/L3 HOLD 条件 | ASQ-3、SWYC 等发展筛查；任何适龄判断、量表、评分、解释、转介和专业评估均为 L2 HOLD。 |
| 输入与状态上限 | 成人表达的服务偏好；不得保存能力/里程碑等级。 |
| 禁止事项 | 发展年龄、学习能力分、雷达图、教育预测、与同龄/其他家庭比较。 |
| Human Gate | 需要标准化工具、专业解释、教育/医疗转介、学校数据或第三方信息时。 |
| fail-closed | 缺许可、年龄/语言不适配、无培训/解释/转介、无有效 consent 时，不呈现或收集工具内容。 |
| 文本等价 | 用“想进一步了解哪些支持方向”而非“测出发展状态”。 |
| 未来 Gate 条件 | 工具正版与电子化权、中文/本地化、适龄、培训、解释、转介、隐私、退出、Human/App Gate。 |

### D6｜社会情绪与行为支持

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 允许家庭表达希望了解可用支持方向，不判断儿童心理状态、行为风险或社会情绪等级。 |
| L0/L1 可做边界 | 成人的服务偏好确认、已准入候选、家庭决定/NO_ACTION。 |
| L2/L3 HOLD 条件 | ASQ:SE-2、SDQ、PSC 等工具；精神心理/行为筛查、解释、危机判断和转介均为 L2/L3 HOLD。 |
| 输入与状态上限 | Need/Intent/Decision；不记录症状、量表分数、风险级别。 |
| 禁止事项 | 心理诊断、情绪分、行为问题标签、风险预测、公开/跨家庭报告。 |
| Human Gate | 自伤/他伤、虐待、急性精神健康、安全、专业服务与未成年人参与。 |
| fail-closed | 不存在本地资源、人类责任或安全 SOP 时，不呈现筛查题、不收集敏感信息、不自动路由。 |
| 文本等价 | “希望获得怎样的家庭支持”而非“孩子情绪是否正常”。 |
| 未来 Gate 条件 | 工具授权、专业解释、危机路径、保密/例外告知、转介网络、误报/漏报管理与独立 Gate。 |

### D7｜家长压力与家庭福祉

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 允许家庭表达希望获得养育支持或服务安排，不对家长能力、家庭质量或心理状况评分。 |
| L0/L1 可做边界 | “我希望获得更多养育支持”的服务需要确认与共同决策。 |
| L2/L3 HOLD 条件 | PSI、PSS 或任何压力筛查；心理健康评估、解释、转介、危机处理均 HOLD。 |
| 输入与状态上限 | 服务偏好与家庭决定；不得保留压力等级/分值。 |
| 禁止事项 | 家长胜任力评级、压力等级、家庭健康分、会员定价、营销分层。 |
| Human Gate | 心理健康、危机、家庭暴力、真人专业支持或临床转介。 |
| fail-closed | 无专业解释和安全路径时，不能采集工具结果或给出结论。 |
| 文本等价 | “你是否希望看到更多养育支持选择？”而不是“测测你的压力”。 |
| 未来 Gate 条件 | 许可、适配、解释责任、转介和危机路径、最小数据、撤回、审计及独立 Gate。 |

### D8｜亲子互动观察

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 说明某些互动观察属于受训专业人员的工作，不把家庭日常记录转为自动观察。 |
| L0/L1 可做边界 | 无自动观察；最多让家庭了解当前未提供此类自动评估。 |
| L2/L3 HOLD 条件 | NCAST-PCI、PICCOLO 等观察工具、现场/视频观察、专业反馈、督导和服务交付全为 L2 HOLD。 |
| 输入与状态上限 | 当前无输入；不得收集视频、音频、照片或儿童直接表现。 |
| 禁止事项 | 自拍分析、视频 AI 打分、亲子互动分、父母标签、儿童表现预测。 |
| Human Gate | 受训观察者、专业督导、知情同意、服务合同和隐私协议。 |
| fail-closed | 无受训人员、许可、观察协议、隐私控制或儿童/监护人权利说明时，禁止观察/记录。 |
| 文本等价 | 文字说明服务不可用或需要后续独立专业路径。 |
| 未来 Gate 条件 | 正版工具、培训/认证、人工监督、儿童权益、数据/影像治理、退出与独立 Gate。 |

### D9｜家庭安全与危机

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 识别普通家庭服务流程不能安全处理的情形，并安全停止；不是危机筛查、诊断或处置服务。 |
| L0/L1 可做边界 | 仅提供通用的退出/安全停止说明；不收集危机细节。 |
| L2/L3 HOLD 条件 | 所有危机/安全筛查工具、风险判断、安全计划、人工值守、紧急升级和转介均为 L3 HOLD。 |
| 输入与状态上限 | 无危机数据采集；仅系统审计“自动路径未继续”。 |
| 禁止事项 | 自动风险分、自动报警、自动外发、自动转介、危机承诺、营销触达。 |
| Human Gate | 本地资源、法务/伦理审查、人工责任、未成年人保护、升级 SOP、误报/漏报责任。 |
| fail-closed | 无本地资源/责任人/SOP 时，不呈现普通危机问卷，不声称可处理，不收集更多信息。 |
| 文本等价 | 纯文本安全退出、求助边界与本地资源待 Gate 后的可用说明。 |
| 未来 Gate 条件 | 本地资源签约、法务/伦理评审、人工值守、SOP 演练、数据最小化、审计、误报/漏报处理与独立 Gate。 |

### D10｜工具、证据与服务资格治理

| 项目 | 设计定义 |
|---|---|
| 服务边界 | 使 Family 能审阅某工具/方法/资源是否具备未来准入条件。 |
| L0/L1 可做边界 | 仅让家庭看到已准入资源的最小来源/边界摘要；不暴露评分规则或内部工具目录。 |
| L2/L3 HOLD 条件 | 任何标准化工具、专业观察或危机工具的实际接入与数字化使用。 |
| 输入与状态上限 | 静态工具元数据、证据/许可/培训/转介/有效期/Gate 状态；零真实家庭数据。 |
| 禁止事项 | 把工具目录当成推荐引擎、效果排行榜、供应商竞价或商业撮合。 |
| Human Gate | 工具权利/许可、专业责任、版本变更、争议、退出、证据升级。 |
| fail-closed | 许可、适龄、培训、解释、转介、隐私、Human Gate 任一缺失则维持 `HOLD`。 |
| 文本等价 | 所有治理状态与家庭可见摘要可文字呈现。 |
| 未来 Gate 条件 | Intake、证据包、版本有效期、审计、数据/安全/专业/App Gate 和总架构师裁决。 |

## 4. 未来 Gate 条件汇总

| Gate 条件 | 适用能力域 | 未满足时的默认状态 |
|---|---|---|
| 正版、电子化、翻译、计分、报告与地域许可 | D5–D8 的标准化/观察工具 | L2 HOLD。 |
| 适龄/适用人群与本地化 | D5–D8 | L2 HOLD。 |
| 培训/认证、解释与督导责任 | D5–D8 | L2 HOLD。 |
| 本地转介网络与后续责任 | D5–D7，尤其 D9 | L2/L3 HOLD。 |
| 人工值守、紧急升级 SOP、法务/伦理、未成年人保护 | D9 | L3 HOLD。 |
| 数据最小化、Consent/撤回、文本等价、审计与退出 | 全部域 | 不进入任何运行时。 |
| 独立 App/Data/Human/Architecture Gate | 全部未来接入 | 不自动解冻。 |

## 5. 最终不变量

> **能力域不是人的标签，而是平台为家庭服务时必须遵守的边界。**

1. 不存在“某家庭属于 D6”或“某孩子的 D5 等级”。
2. 不存在能力域总分、权重、雷达、排序、成熟度等级或跨家庭比较。
3. Need/Intent 是家庭表达；Decision 是家庭选择；它们都不是专业事实或效果结论。
4. L2/L3 的研究与登记不构成采购、接入、数字化、工具运行、模型训练或 HOLD 解冻。
5. 任何未来实现必须以独立任务契约、准入证据包、Human Gate 与总架构师裁决重新开始。
