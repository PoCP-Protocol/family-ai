# L0「当下需要与服务偏好确认」UX/Gate 文案资产
## Family L0 Need & Service Preference Copy Governance（草案 001）

> **状态：`DRAFT_FOR_ASSESSMENT_APP_GATE_DECISION_INPUT`。**
>
> 本文只定义前台 UX/Gate 文案资产，适用于未来 App、Web 或小程序的文本等价路径。它不授权页面实现、问卷运行、DTO/API/数据库改动、标准化工具接入、模型调用或真实家庭数据处理。

## 1. 业界做法的可迁移原则

家庭中心服务的共同原则是尊重家庭定义与选择、以公开客观的信息支持参与、让家庭与服务方共同决定，而不是用系统结论替代家庭决定。[1] [2] 共同决策在存在多个合理选择时，应帮助家庭理解选择边界和表达偏好，而不把一个选项包装成唯一“正确答案”。[3]

对 Family 的文案翻译是：

> **听见家庭表达 → 说明为什么问 → 展示当前已准入候选 → 家庭决定继续、返回或 NO_ACTION。**

这不是筛查、诊断、评分、成长报告或最佳方案生成器。

## 2. 命名规范

| 前台位置 | 推荐名称 / 文案 | 禁止名称 / 文案 | 允许写入上限 |
|---|---|---|---|
| 功能入口名 | **选择你现在需要的支持** | 免费家庭测评、成长测评、AI 诊断、成长体检、家庭评分 | 无写入；只进入说明页。 |
| 次级入口名 | **确认当下需要与服务偏好** | 测出孩子成长状态、家庭画像、风险检测 | 无写入；只进入说明页。 |
| 页面 1 标题 | **你想先理清哪一类家庭支持？** | 你的家庭有什么问题？孩子哪里落后？ | 候选 Need。 |
| 页面 2 标题 | **你希望先看怎样的支持方式？** | 系统将为你推荐最佳方案 | 候选 Intent。 |
| 候选页标题 | **当前可以查看的支持选择** | 精准推荐、最适合你的方案、系统诊断结果 | 只读 admitted candidates。 |
| 决策页标题 | **由你决定下一步** | 立即执行方案、开启成长干预 | Decision 或 NO_ACTION。 |
| 无候选页标题 | **现在没有可安全展示的支持选择** | 暂无匹配结果、你的问题较复杂 | 无写入或 NO_ACTION。 |
| 过程回看标题 | **这一步对你的家庭有没有帮助？** | 成长效果反馈、能力提升报告 | 候选主观 FollowUp；不是 L0 评分。 |

## 3. 允许话术与状态写入上限

### 3.1 Need：表达当下需要

| 文案场景 | 允许文案 | 说明 | 写入上限 |
|---|---|---|---|
| 首屏说明 | “你可以选择现在最想获得哪一类家庭支持，也可以直接跳过。” | 先给选择权。 | 无。 |
| 需要选择 | “此刻，你最希望先理清什么？” | 询问服务需要，不询问能力、症状或风险。 | 候选 Need。 |
| 可选方向 | “亲子沟通”“日常协作”“想先看看可用支持”“暂不确定” | 这些是服务方向词，不是问题类别或诊断。 | 候选 Need。 |
| 自由表达 | “如果愿意，可以用自己的话补充。也可以留空。” | 自由文本可选；不承诺自动理解或分析。 | 候选 Need，须最小化。 |
| 提交后确认 | “已记录你此刻想先理清的支持需要。它不是对孩子或家庭的判断。” | 防止 Need 被误读为事实结论。 | Need。 |

### 3.2 Intent：确认服务偏好

| 文案场景 | 允许文案 | 说明 | 写入上限 |
|---|---|---|---|
| 偏好说明 | “你希望先看哪一类支持方式？选择后仍可返回或暂不行动。” | 不承诺一定提供服务。 | 无。 |
| 偏好选项 | “先看可阅读的支持材料”“先看看一个可暂停的下一步”“暂时不选择” | 仅表达服务偏好。 | 候选 Intent。 |
| 不确定选项 | “我还不确定，先看看说明。” | 不强迫作决定。 | 无，或候选 Intent 仅在确认时。 |
| 确认语 | “你选择先查看这个方向。我们只会展示当前已准入的候选。” | 说明候选资格而非推荐。 | Intent。 |

### 3.3 admitted candidates：只读展示

| 文案场景 | 允许文案 | 说明 | 写入上限 |
|---|---|---|---|
| 页面说明 | “以下是当前可以展示的已准入候选。是否继续由你的家庭决定。” | 明确平台不替家庭决定。 | 只读 admitted candidates。 |
| 候选卡片 | “支持方式”“适用的服务方向”“来源与准入说明”“你可以查看、返回或暂不行动。” | 只述来源/准入/方向；不宣称效果。 | 只读 admitted candidates。 |
| 没有候选 | “现在没有可安全展示的选择。你可以返回修改偏好，或暂不行动。” | 不把缺少候选归因为家庭问题。 | 无。 |
| 不可选资源 | 不显示，或显示“目前不可提供”且不解释敏感内部原因。 | 资源准入失败必须 fail-closed。 | 无。 |

### 3.4 Decision / NO_ACTION：家庭明确决定

| 文案场景 | 允许文案 | 说明 | 写入上限 |
|---|---|---|---|
| 继续按钮 | **“选择这个下一步”** | 明确是家庭主动选择。 | 候选 Decision。 |
| 返回按钮 | **“返回看看其他选择”** | 不产生 Decision。 | 无。 |
| NO_ACTION 按钮 | **“现在先不继续”** | 正常、被尊重的选择。 | NO_ACTION。 |
| NO_ACTION 确认 | “已记录：你的家庭现在选择暂不行动。之后可随时重新确认需要。” | 不赋予负面含义。 | NO_ACTION。 |
| 服务前说明 | “只有在你明确选择继续且当前条件满足时，才会进入下一步。” | 说明 Decision 和资格的双重条件。 | 无。 |

## 4. 禁止话术清单

| 禁止类别 | 禁止例子 | 禁止原因 | 合规替代 |
|---|---|---|---|
| 分数/等级 | 成长分 78、家庭 LV.3、压力等级、沟通能力 60 分 | 将服务表达转为评分/比较。 | “你现在希望先获得哪类支持？” |
| 诊断/风险 | AI 诊断、风险提示、孩子问题、情绪异常 | 形成心理/临床/风险结论。 | “如果你希望进一步了解，我们会说明当前可用的下一步与边界。” |
| 画像/类型 | 你是焦虑型家长、你的家庭属于冲突型 | 产生画像和长期标签。 | “你可以选择此刻最想先理清的支持方向。” |
| 能力判断 | 孩子社交能力弱、家长陪伴能力不足 | 评价孩子/家长能力。 | “你希望先看看亲子沟通方面的支持吗？” |
| 最佳推荐 | 为你推荐最佳方案、精准匹配、系统最懂你 | 将平台推断置于家庭决定之上。 | “展示当前已准入候选，由家庭决定是否继续。” |
| 效果承诺 | 90 天改变、保证改善、见证成长结果 | 无证据或将过程写成结果。 | “这是一个可暂停的服务过程选择，不代表结果承诺。” |
| 商业/会员诱导 | 完成测评领取权益、付费解锁诊断、升级会员获得方案 | 把敏感表达捆绑商业转化。 | “你可以跳过、暂停或退出；回答不会决定你的家庭价值或资格。” |
| 跨家庭比较 | 超过 80% 家庭、同龄排名、第 3 名 | 引入比较、压力与公开化。 | 不显示比较性信息。 |
| 自动服务 | 已为你生成任务、已自动安排服务 | 绕过家庭明确 Decision 和 T2。 | “由你的家庭决定是否继续。” |

## 6. 标准说明句

### 6.1 为什么问

> “我们只想了解你现在希望获得哪类家庭支持，以便展示当前已准入的选择。你可以跳过，也可以随时返回。”

### 6.2 不会怎么用

> “你的回答不会生成孩子或家庭的分数、等级、风险、画像或成长结论，也不会用于公开比较、广告、会员定价或模型训练。”

### 6.3 如何撤回

> “你可以随时退出本次确认；如撤回服务用途同意，后续不会继续复用相关服务上下文。已留存的审计记录仅用于安全与责任追溯，不会变成成长标签。”

### 6.4 候选展示

> “我们只展示当前已准入的候选。它们不是对你家庭的最佳判断，也不代表效果承诺。是否继续由你的家庭决定。”

### 6.5 跳过 / 退出

> “不想回答也没关系。你可以跳过、返回，或现在先不继续；这不会影响你之后再次确认需要。”

### 6.6 文本等价

> “所有关键内容都有文字说明。即使图片、动效、语音或其他辅助功能不可用，你仍可查看说明、选择、返回、退出或暂不行动。”

### 6.7 普通流程无法处理的事项

> “如果你的问题需要专业、紧急或其他人工支持，当前页面不会自动判断或安排服务。你可以停止本流程，并在适当渠道寻求支持。”

## 7. 文案与状态写入的审核表

| 文案出现位置 | 允许状态 | 禁止的隐含状态 |
|---|---|---|
| 解释页、为什么问、不会怎么用、撤回说明 | 无 | Need、Intent、诊断、风险。 |
| 当下需要选择 | 候选 Need | 能力、风险、评分、标签。 |
| 服务偏好确认 | 候选 Intent | 自动推荐结论、服务资格。 |
| 候选展示 | 只读 admitted candidates | Decision、Plan、ServiceCase。 |
| 继续选择 | Decision（家庭明确确认后） | 自动 Case、效果事实。 |
| 暂不行动 | NO_ACTION | 失败、低参与、家庭问题。 |
| 服务过程回看 | 主观 FollowUp（另有独立动作） | 成长结果、效果证明、工具证据升级。 |

## 8. 文案负例验收清单

| 编号 | 验收负例 | 必须结果 |
|---|---|---|
| COPY-01 | 出现“测评”“诊断”“评分”“画像”“风险等级”“最佳方案”作为 L0 前台核心文案 | 文案审查失败，不得进入候选版本。 |
| COPY-02 | 任一 Need/Intent 文案暗示儿童能力、家长能力、心理/临床结论或成长结果 | 文案审查失败。 |
| COPY-03 | 候选展示文案诱导家庭认为已自动生成 Plan/Case | 文案审查失败；展示保持只读。 |
| COPY-04 | `NO_ACTION` 被写成“忽略建议”“放弃改善”“你尚未完成” | 文案审查失败；替换为中性、可返回选择。 |
| COPY-05 | 未准入资源通过“相似推荐”“更适合你”语言出现 | 文案审查失败；资源不可显示。 |
| COPY-06 | 文案把 E1 材料、案例、FollowUp 或过程数据写成效果证明 | 文案审查失败。 |
| COPY-07 | 完成确认与会员、支付、积分、拼团、分享、优惠、等级等绑定 | 文案审查失败。 |
| COPY-08 | 退出、跳过、撤回或文本路径缺失 | 文案审查失败。 |
| COPY-09 | 高风险/专业/危机事项被写成普通选择题或自动服务承诺 | 文案审查失败；转 Human Gate / fail-closed。 |
| COPY-10 | 图表、色块、动画或模型不可用时，用户无法理解或完成退出/NO_ACTION | 无障碍/文本等价验收失败。 |
| COPY-11 | 同一页面文案使 Need、Intent、Decision 或 FollowUp 的事实边界混淆 | 状态语义审查失败。 |
| COPY-12 | 文案声称“平台会根据回答推荐最佳方案” | 替换为“平台展示当前已准入候选，由家庭决定是否继续”。 |

## 9. 文案进入未来 App Gate 的必问问题

1. 每一条文案是否能明确映射至“无写入、Need、Intent、只读 admitted candidates、Decision 或 NO_ACTION”之一？
2. 是否所有 Need/Intent 都被表述为家庭自愿表达，而非系统判断？
3. 是否完整保留跳过、返回、退出、撤回、NO_ACTION 和文本等价路径？
4. 是否候选展示与家庭 Decision 严格分离，且零自动 Plan/Case？
5. 是否排除所有分数、等级、诊断、画像、效果、商业诱导和跨家庭比较？
6. 是否高风险、专业、真人、第三方、儿童直接作答和外部资源请求都会停止自动路径？
7. 是否 App Gate、Data Gate、Human Gate 尚未裁决前，文案资产不会被误当作运行时上线授权？
