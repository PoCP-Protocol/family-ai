# GOV-002 — IAM HARDENING

Status: PILOT_MINIMUM_REQUIRED
Blocks M2 implementation: NO
Blocks external Pilot: YES

目标：

把M1 minimal permission升级为真实Pilot可用的最小身份与授权闭环。

至少明确：

- Account ↔ Person binding
- Family membership / role
- Guardian authorization
- RBAC + contextual ABAC
- Consent vs access permission separation
- Staff / Advisor / Expert role
- Minor data access purpose
- audit / trace
- revoke / role change
- unauthorized read/write E2E

禁止顺便建设大型企业IAM平台。
