# UI-25 家庭成长交流内容流 PDCA 001

## 用户问题与本轮目标

家长在了解活动主题之后，可能希望看看其他家庭如何将亲子沟通、日常节奏或共同学习落实到生活中。本页应提供**可浏览的经验片段**，帮助家庭获得信息和被理解的感觉，而不是将浏览量、点赞、回复、作者等级或“成长变化”当作家庭优劣或儿童效果证据。

在线家长同伴支持研究指出，父母常从线上社区获得信息性与情感性支持、连接感和共同体感；但现有证据对于健康或儿童行为效果并不充分，而且批评、两极化争论和缺少规范也可能出现。[1] 因此，本轮将 UI-25 设计为家庭可读的、受控的经验摘要流：内容只帮助家长了解可尝试的日常做法，不下教育效果结论，也不默认开启发布、评论、点赞、收藏、分享或外部互动。

| 用户 | 需要的体验 | 本轮实现 |
|---|---|---|
| 家长 | 从活动主题继续了解贴近日常的他人经验 | 中性经验摘要、主题标签与阅读详情入口 |
| 孩子 | 不被家庭公开比较、打分或标签化 | 不展示儿童身份、成长结论、排名、热度或互动统计 |
| 家庭 | 可停在阅读，不被催促加入讨论或发布 | 明确“先看看，是否继续由家庭决定”的提示 |
| 平台 | 验证活动主题到交流内容的血缘且不产生社区副作用 | 家庭范围只读投影与 UI-27 阅读说明入口 |

## 外部研究与产品判断

系统综述纳入 21 项关于幼儿母亲线上同伴支持的研究，归纳出信息支持、情感支持和连接感等常见支持类型，同时指出干预性证据有限、效果结论不应夸大。[1] 该研究亦记录批评、分歧、两极化讨论及缺乏规范等负面体验。因此，UI-25 将内容定位为**可供家庭理解和借鉴的经验材料**，而不将其显示为专业建议、儿童评估、效果证明或群体共识。

关于家庭声音和知情选择的研究强调，支持方案应贴近家庭的偏好、情境与自主决定，而不以系统要求取代家庭选择。[2] 本轮据此允许家长只读浏览，并把下一步限定为“查看这段经验说明”或返回活动主题；不把任何浏览行为升级为发布、报名、联系或服务决定。

## 基线与动态内容边界

UI-25 对标 `apps/web/public/bangyang-reference/parent-community-reference-552x1034.png`。基线图包含社区标题、搜索、分类、分享横幅、话题图标、作者头像、等级、热度、图片、点赞、评论与收藏等视觉元素。它们均保留为视觉基线，不能被解释为真实的家庭动态数据。

动态交流内容流将追加在基线图后方，只呈现：经验标题、可读摘要、主题标签和阅读说明入口。动态区不呈现作者识别信息、儿童照片、儿童姓名/年龄/学校、作者等级、热度、点赞、回复、收藏、浏览量、排行榜、公开分享、评论或发布功能。

## 数据与流程边界

> UI-22 家庭成长活动目录 → UI-25 家庭成长交流内容流 → UI-27 家庭经验说明。

| 可读投影 | 本轮不创建或不展示 |
|---|---|
| 受控经验片段的标题、摘要、主题标签、阅读说明入口 | Post、Comment、Reaction、收藏、分享、媒体、作者资料 |
| 家庭浏览的活动主题上下文 | 点赞量、回复量、热度、等级、排名或互动统计 |
| 返回活动目录的入口 | 发布、评论、举报、外发、通知、审核处置 |

本轮不会调用模型，不会把自由文本写入核心对象，也不会执行外部副作用。后续若引入真实社区内容，必须以明确的可见范围、授权、审核和命名动作承载，不能复用本轮只读摘要作为已发布社区内容。

## 验收标准

1. UI-22 可进入 UI-25；UI-25 可回到 UI-22。
2. UI-25 只显示家庭可读经验摘要，并可进入 UI-27 说明页；全程没有 POST、点赞、评论、收藏、分享、通知或外部请求。
3. 动态区不显示作者身份、儿童识别信息、热度、点赞、评论、等级、排名、效果结论或工程术语。
4. 自动化测试覆盖活动上下文透传、阅读说明往返、无写入以及 Web/API 全量回归。
5. 移动端复核确认动态内容位于社区原始基线之后，原图中的互动元素不构成动态事实。
