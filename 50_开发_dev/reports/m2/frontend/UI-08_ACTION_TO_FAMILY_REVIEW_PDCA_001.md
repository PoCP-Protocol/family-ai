# UI-08 行动记录到家庭成长回顾 PDCA 001

> **本轮范围**：把 UI-09 已记录的今日家庭行动，连接到 UI-08 的家庭成长回顾。页面帮助家长“看见做过什么、回想当时的互动、决定是否保留或调整下一步”，而不把一次行动记录写成孩子能力、教育效果或因果结果。

| 字段 | 本轮定义 |
|---|---|
| `PDCA_ROUND` | `UI09_ACTION_TO_UI08_REVIEW_001` |
| `SOURCE_UI` | UI-09（今日成长任务） |
| `TARGET_UI` | UI-08（家庭成长报告/成长回顾） |
| `USER_JOURNEY` | 完成或部分完成今日行动 → 查看家庭回顾 → 看见本次已记录行动 → 用非评判问题回想当时互动 → 回到计划或下次行动。 |
| `CHILD_EXPERIENCE` | 不被任务完成与否定义；页面不对孩子作能力、性格或结果判断，家长可带着好奇而非评判回到互动。 |
| `PARENT_EXPERIENCE` | 不用填写冗长表格或接受系统评价；获得短而清楚的回顾提示，知道下一次可以保留、缩小或调整做法。 |
| `FAMILY_EXPERIENCE` | 强调关系与共同节奏；鼓励听见彼此，而不是把计划变成考核。 |
| `PERSISTENCE` | UI-09 的真实 `CompleteGrowthAction` 继续记录行动完成；其成功后另记录家庭内的 UI-09 回顾入口事件，使 UI-08 可跨页面读取。 |
| `FACT_BOUNDARY` | 事实仅是“行动已记录”；回顾问题和家庭理解属于视角/反思提示，不是儿童诊断、Outcome、因果效果、总分或排名。 |
| `FRONTEND_RULE` | 前台不显示 DEV、synthetic、模型网关、审核、证据等级、测试回执、命令或内部数据源。 |

## 1. Plan：用户需求、研究与视觉基线

UI-08 基线资产为 `apps/web/public/bangyang-reference/ui18/growth-02-ai-report.png`，尺寸为 240 × 545px。图中显示“家庭成长报告”标题、孩子信息条、五角维度图、优势/困难/优先建议标签、7 天—30 天—90 天成长路径以及“生成个性化方案”CTA。该图中的数值、标签和建议为视觉基线内容，不能作为本轮家庭的真实事实、总分、比较、诊断或结果。动态回顾卡只能置于基线图之后，不覆盖其结构。

反思设计以“先观察、再理解、最后决定下一步”为顺序。Head Start 的反思实践资料将反思描述为从即时体验中稍稍退后，梳理所观察与所感受的过程；它强调先邀请家长说出观察，再一起探索孩子的体验，并用成功经验、误解澄清和未奏效时的不同尝试来支持后续行动。[1] 亲职正念模型同样强调专注倾听、非评判接纳、觉察情绪、关系中的自我调节与对亲子双方的慈悲；这些是对话设计输入，而非对家庭的效果承诺。[2]

| 用户问题 | 体验回答 | 数据与边界 |
|---|---|---|
| “我刚完成了任务，接下来有什么意义？” | 先确认“本次行动已记录”，再提示不急着判断效果。 | `GrowthAction` 是事实；回顾提示不产生 Outcome。 |
| “孩子当时不配合，是不是我做错了？” | 以“你注意到了什么”“下次什么会更合适”替代成败评价。 | 家长理解属于 Perspective，不写入核心画像。 |
| “我不想被分数和报告压力追着走。” | 不展示完成率、孩子排名、总分或效果分级。 | UI-08 基线图的视觉数字不参与动态判断。 |
| “如何把今天的经历放回长期计划？” | 回顾卡提供“回到 90 天计划”入口，计划仍可按家庭节奏调整。 | 只读导航；不自动更新正式 Plan 或任务。 |

## 2. Do：最小实现设计

共享 Core Growth 投影在 UI-08 卡新增 `action_review`。该投影仅在同一家庭的 UI-09 已完成行动后、并成功记录回顾入口事件时展示；字段包括关注方向、面向家长的确认文案、一个观察问题、一个温和的下次提示、计划回访路由和 `action_recorded` 状态。该投影不读取或推断孩子表现，不写 Reflection 内容，不新建任务、Outcome 或 Evidence。

UI-09 的既有完成按钮仍只调用 `CompleteGrowthAction`。只有该动作成功或幂等回放成功后，前端才追加一次家庭内 UI-09 回顾入口记录，并显示“查看家庭回顾”；若回顾入口记录失败，任务完成事实仍保持有效，前台只不显示跨页回顾入口。UI-08 读取该家庭的 Core Growth 投影，显示回顾卡；无记录时只保留原始基线，不伪造回顾。

## 3. Check：测试与视觉验收

测试覆盖：UI-09 成功完成后才产生 UI-08 回顾入口；相同家庭与关注方向的回读；幂等；不同家庭不可读取；回顾投影没有 Outcome/排名/总分/诊断字段；回顾入口失败不撤销真实行动完成；UI-08 基线图保持；UI-09 完成后只出现自然的“查看家庭回顾”；前台没有工程术语。

视觉验收重点：UI-08 原图完整保留；回顾卡在原图下方；卡片内容简短、可读、没有“表现好/差”“评分”“证据”等压力性措辞；“回到 90 天计划”是唯一明确下一步，不替代当前计划结构。
