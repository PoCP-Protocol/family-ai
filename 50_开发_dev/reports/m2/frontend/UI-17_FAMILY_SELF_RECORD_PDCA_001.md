# UI-17 家庭自主记录 PDCA 001

## 1. 身份纠偏与本轮范围

UI-17 的视觉基线是“积分商城”：静态图包含成长积分、任务分值、可兑换商品和购买入口。平台总规则禁止家庭排名与总分；因此本轮不把静态积分、分值、任务完成数、兑换商品、价格或权益变成动态数据。UI-17 在本轮被实现为**家庭自主记录入口**：当家庭已经完成一次真实的今日行动后，可以回看这次行动，并选择继续日常行动或回到家庭回顾。

| 项目 | 本轮实现 | 明确不做 |
|---|---|---|
| 用户价值 | 让家长与孩子从“完成了什么”回到“接下来想怎么做”，保留可暂停、可回看的选择 | 积分余额、任务分值、连续天数、兑换、奖励、权益、家庭排名或儿童评价 |
| 数据关系 | 读取同一家庭既有的 UI-09 行动回顾入口；复用 UI-08 家庭回顾与 UI-09 今日行动 | 创建 PointLedger、Reward、Entitlement、Order 或支付对象 |
| 前台动作 | 查看家庭回顾；继续今天的行动 | 积分结算、奖励领取、商品兑换、购买、通知或外发 |
| 视觉策略 | 原始积分图完整保留，在其后追加轻量的家庭记录卡 | 重绘静态分数、积分、价格、兑换和购买区 |

## 2. 用户需求与设计依据

孩子和家长更需要被支持去理解一项行动、选择下一步并保持关系，而非被分数、外在奖励或同伴比较推着完成。哈佛大学发展中儿童中心的实践资料指出，儿童在有选择空间时更可能持续投入，并建议在可能时优先运用好奇心和可达成目标，而不是承诺奖励；它也强调应赞赏过程而非结果。[1] 自我决定理论的家庭实践资料同样提出，家长应理解儿童视角、避免为活动增加激励或评价，并以考虑周到而非施压的表达支持参与。[2]

> “Provide incentives only when necessary… rather than promising a reward.” — Center on the Developing Child at Harvard University.[1]

本轮只将这些资料用于界面表达：使用“家庭小记”“可以暂停或换一种方式”的过程语言；不推断教育效果，不用积分标识儿童价值，也不把一次任务记录解释成成长结果。

## 3. 基线阅读与视觉边界

UI-17 基线图为 `commerce-05-points-task.png`，尺寸为 244 × 545 像素。它展示静态的积分余额 `1280`、任务分值、兑换商品和购买按钮。本轮完整保留原图，并将积分、分值、兑换、价格、权益和购买按钮视作视觉基线而非动态事实。

动态家庭记录卡固定追加在原图之后，只显示行动已记录后的温和确认、当前可选择的下一步与两个既有入口。动态层不得显示数字化进度、排名、积分、分值、兑换、商品、价格、奖励、权益、订单、支付、外发、通知或工程过程术语。

## 4. 数据与行动边界

```text
UI-09 CompleteGrowthAction
  └─ UI-09 OPEN_SYNTHETIC_FAMILY_ACTION_REVIEW event
       └─ UI-17 family self-record read projection
            ├─ UI-08 family review
            └─ UI-09 daily action
```

UI-17 仅从同一家庭已记录行动的受控流程事件读取“可回看”状态。它不创建积分、规则、账本、兑换或权益对象；两个入口只是页面导航，不改变任务完成事实，也不产生外部效果。

## 5. 验收标准

1. 仅在同一家庭的行动已记录后显示 UI-17 家庭自主记录卡；未记录时保持不显示。
2. 卡片仅提供“查看家庭回顾”和“继续今天的行动”两个既有入口。
3. 用户前台不显示 DEV、synthetic、no-op、模型、审计、积分、分值、兑换、奖励、权益、订单、支付、外发或通知术语。
4. UI-17 原始积分基线完整保留；动态内容位于原图之后。
5. 完成 Core Growth 单元、流程事件集成、前端页面对象、API/Web 全量回归和移动端视觉复核后，限定提交本轮文档与程序。

## 6. 移动端视觉复核

在 `?product=test-loop&page=commerce-points` 挂载同一家庭已记录行动的 UI-17 投影后，原始积分页视觉完整保留。家庭小记卡置于基线图之后，呈现“我们已经为今天留下一条小记录”、温和的可暂停提示，以及“查看家庭回顾”“继续今天的行动”两个入口。动态卡未显示积分、分值、奖励、兑换、权益、订单、支付、外发或工程过程术语。
按钮区复核通过：两个入口并列、间距清晰，分别只进入既有家庭回顾与今日行动页面；动态区域没有积分、奖励、兑换、权益、订单、支付、通知或外发功能。
