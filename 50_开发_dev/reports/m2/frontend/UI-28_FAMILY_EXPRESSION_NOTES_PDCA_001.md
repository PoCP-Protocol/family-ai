# UI-28 家庭表达小记 PDCA 001

## 用户问题与本轮目标

UI-26 已让家庭把一段想法先记为私有草稿。家长下一步需要的不是看到“我的社区”中的等级、粉丝、互动或奖励，而是能确认一段家庭想法已经被家庭保留，并可回到成长计划或家庭交流继续查看。本轮将 UI-28 定位为**家庭表达小记**：仅回读同一家庭已经记下的表达草稿，帮助家庭保留自主决定权，不把草稿转化为公开动态、互动表现或儿童成长评价。

| 用户 | 需要的体验 | 本轮设计 |
|---|---|---|
| 家长 | 知道家庭想法已被保留，且可以之后再改或不分享 | 提供家庭范围的只读小记回看与返回入口。 |
| 孩子 | 不因家庭表达被识别、暴露或贴上标签 | 动态区域不展示姓名、年龄、学校、照片、媒体、等级或互动数据。 |
| 家庭 | 能保留并共同决定表达节奏 | 强调“留给家庭”“之后再决定”，不提供公开、发送或互动动作。 |
| 平台 | 验证 UI-26 到 UI-28 的可追溯血缘 | 只读取既有受保护草稿动作的家庭范围记录，不新建 Post、Comment、Reaction 或 Visibility 对象。 |

## 研究输入与产品判断

UNICEF 建议家长审查数字服务的隐私与权限设置，最小化不必要的数据收集与共享；其指南也提醒，儿童的全名、生日、地址、电话和学校等信息应谨慎对待，并鼓励家庭在发布或分享前停下来思考。[1] 因此，本轮采用**私有默认、儿童信息最小化、无默认外发**的呈现方式。

内华达大学合作推广的家庭叙事资料将家庭故事描述为记录日常经历和形成共同历史的一种方式，同时强调故事的内容之外，也应关注讲述的过程、时机与情绪细节。[2] 这支持 UI-28 把小记设计为可回看的家庭过程，而不是对儿童或家庭的结果证明。

> 本轮小记仅确认家庭保留了一段表达草稿；它不代表公开发布、他人阅读、获得互动、撤回完成，或任何教育效果结论。

## 视觉基线与动态内容边界

UI-28 对标 `apps/web/public/bangyang-reference/my-community-reference-560x1030.png`。原图为常规可读的 560×1030 纵向页面，不需要分块处理。头像、粉丝、关注、积分、等级、发布列表、挑战、权益和奖励只作为历史视觉基线保留，**不会进入动态判断或家庭成长评价**。动态小记卡追加在原图之后。

| 动态可读取内容 | 本轮不展示、不创建或不解释的内容 |
|---|---|
| 同一家庭草稿的中性保留状态 | 公开帖、作者身份、粉丝、关注、等级、积分、奖励与权益 |
| “之后再决定”的家庭节奏提示 | 儿童个人信息、照片、音视频、位置、学校与标签 |
| 回到家庭交流、回到成长计划的入口 | 评论、回复、点赞、收藏、分享、下载、通知、举报、审核与外发 |

## 数据与流程边界

> UI-25 家庭经验阅读 → UI-26 家庭分享草稿 → UI-28 家庭表达小记。

UI-28 仅读取现有受保护体验动作中属于当前家庭的 `PUBLISH_TEMPLATE` 草稿事件或客户投影摘要。前台将其映射为“家庭想法已保留”的中性状态；不推断文本内容、儿童状态、互动量、可见范围或结果。读取失败时只显示自然的重试提示，不以本地替代数据伪装记录已存在。

## 验收标准

1. UI-26 的草稿记录成功后可进入 UI-28；UI-28 只读取当前家庭范围内已保留的小记状态。
2. 动态卡不显示公开、作者、儿童身份、媒体、互动、等级、积分、奖励、交易或工程术语。
3. UI-28 不创建、修改、公开、删除、撤回、评论、点赞、通知或外发内容。
4. 自动化测试覆盖同家庭读取、空态、错误态、无跨家庭内容、UI-26 到 UI-28 回流与无写入。
5. 移动端复核确认小记位于“我的社区”原始基线之后，静态社区视觉不构成家庭动态事实。

## 视觉复核记录

在本地页面 `http://localhost:5173/?product=test-loop&page=my-community` 复核 UI-28 空态。原始“我的社区”整张 560×1030 基线图保持完整，小记卡在基线之后追加；卡片采用浅绿色、圆角和两枚并列的家庭内入口，不替换或遮挡原图内容。空态文案只说明“先留下一段想记得的时刻”和之后可回到家庭交流，并未引入工程状态、身份信息、互动、等级、积分、奖励、支付或公开发布文案。

返回“家长社区”后，页面仍保留既有阅读、写下家庭想法与我的社区的透明热点，未额外出现交互入口。本轮 UI-28 的已保存态由自动化血缘测试验证，以避免浏览器可视页面对本地会话状态产生误判。
