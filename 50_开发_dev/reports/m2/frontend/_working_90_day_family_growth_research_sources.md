# 90 天家庭成长方案：外部研究要点（工作底稿）

> 本文件仅作为完整方案设计输入，不把研究结论直接写成对任何家庭或儿童的事实、诊断或效果承诺。

## 研究来源与可用设计启发

| 来源 | 可验证要点 | 对 90 天方案的设计约束/启发 |
|---|---|---|
| Sanders, 2023, *The Triple P System of Evidence-Based Parenting Support*（PMC）<https://pmc.ncbi.nlm.nih.gov/articles/PMC10640495/> | 文献将循证育儿支持描述为可覆盖不同年龄、不同需求和不同强度的多层级系统；强调“最小充分支持”、文化与情境适配、持续评估与实施质量。 | 计划不应一刀切或把所有家庭推入同一强度；需要 `Need/Context`、`SupportIntensity`、`DeliveryMode`、`Re-engagement`、`HumanGate` 和 `Fidelity/Feedback` 对象。90 天只是一个可调整的周期，不能替代转介或专业服务。 |
| Australian Institute of Family Studies, *Effective parenting programs: What does the evidence say?* <https://aifs.gov.au/resources/policy-and-practice-papers/effective-parenting-programs-what-does-evidence-say> | 育儿项目可支持亲子关系、养育实践等多个结果，但不存在对所有人群和结果都最有效的单一项目或组件；应理解家庭个体需要，区分预防、早期干预与治疗型支持。 | 90 天计划必须记录“家庭选择的关注方向”和支持目标，而不是把页面选择转化为儿童标签/诊断；应使用候选行动、家庭反馈、阶段复盘与升级路径；治疗/高风险情况必须进入人工服务/转介边界。 |
| Landry et al., 2008, *A Responsive Parenting Intervention*（PMC）<https://pmc.ncbi.nlm.nih.gov/articles/PMC2570562/> | 研究关注温暖、及时回应、支持儿童注意焦点、语言支架等可观察的养育行为；文中课程采用示范、辅导、回看练习与跨周应用计划。 | 任务编排应以具体、可观察、低负担的父母行动为单位，支持“行动计划→家庭自述/观察→回顾→下一步候选”；不得把单次打卡视为儿童发展结果或因果证明。 |

## 初步能力模型（待与仓库规格和用户资料核验）

1. **阶段计划**：目标/关注方向、阶段、周节奏、候选行动、可选资源、支持强度和家庭确认；90 天草稿不自动成为正式计划。
2. **行动编排**：每日/每周任务、可观察行动提示、暂停/替换/跳过、完成回执、幂等与审计。
3. **反馈与复盘**：父母 Perspective、可核验 Observation、Recommendation 与 Action 分层；阶段复盘产生下一步候选而非效果断言。
4. **服务升级**：对需要更多支持的家庭提供受控咨询需求草稿、人工审核与无外部效果的 Dev 路径；不自动外联。
5. **AI-ready**：模型网关仅能生成受控候选/文本等价物；核心状态仅由 Named Action 写入；必须保存证据来源、规则/模型版本、审计和人工确认状态。

## 设计红线

- 不创建家庭排名、儿童总分、儿童诊断或教育效果承诺。
- 任何自述、反思、分享内容均为 Perspective，不能自动升级为 Fact 或 Outcome。
- 不能把消费、预约、分享、通知、真人服务、权益变更伪装成计划的一部分；这些能力必须走对应 adapter、consent、human gate 和 audit。
- 研究结论仅用于产品设计，不代表对具体用户的医学、心理、法律或教育评估。
