# UI-21 家庭咨询需求草稿 PDCA 001

## 用户问题与本轮目标

家长在看完一个家庭支持主题后，常常需要先把“我想进一步了解什么”记下来，而不是在信息尚不完整时被迫确认咨询、时间、价格或真人服务。家庭中心实践强调家庭拥有知情选择权，应得到完整而中性的选项信息，再依据自身需要决定是否继续。[1] [2]

本轮将 UI-20 的已读主题摘要接到 UI-21。页面只呈现家庭已阅读的主题、适龄参考、可了解方式和“记下咨询需求”入口。请求成功只表示一条家庭范围的咨询需求已经被系统接收；不等于咨询已排期、真人已联系、时间已确认、支付已发生或任何成长效果已得到证明。

| 用户 | 需要的体验 | 本轮实现 |
|---|---|---|
| 家长 | 先了解并保留咨询需求，不被催促决定 | 主题摘要、自然说明、可返回支持说明 |
| 孩子 | 不被评价或贴标签 | 不收集儿童表现、结果或判断性文本 |
| 家庭 | 只使用本家庭已读的支持方向 | UI-20 会话白名单摘要传递到 UI-21 |
| 平台 | 在开发环境验证真实请求与后续服务记录血缘 | 复用家族范围、同意、幂等、审计和无外部效果的既有预约请求 |

## 范围与数据血缘

> UI-20 家庭支持说明 → UI-21 家庭咨询需求草稿 → 受保护的家庭范围咨询请求 → 家庭私有服务记录。

`selectedSupportTopic` 只保存 UI-19 已读取的支持主题摘要。UI-21 先读取该主题可用的候选时段，再向既有 `booking-requests` 端点发送 `page_id=UI-21`、主题引用、版本和候选时段引用。用户界面不显示内部编号、提供者、资质、评价、容量、价格、权益、通知状态、视频地址或审计字段。

| 边界 | 用户前台 | 底层实现 |
|---|---|---|
| 已读主题 | 支持主题、适龄参考、可了解方式 | 家庭范围服务供给读模型 |
| 咨询需求 | “已记下咨询需求” | 受保护的 UI-21 请求、同意与幂等审计 |
| 服务状态 | 不宣称已安排或已联系 | 开发环境请求与服务记录，`external_effect=false` |
| 非目标 | 不出现支付、退款、日历、视频、通知、真人联系或效果结论 | 不调用相应外部适配器 |

## 视觉与前台文案

原始 UI-21 基线 `consultation-booking-reference-492x1008.png` 的服务者、时间、价格、权益与确认操作均保留为视觉基线，不转化为本轮动态事实。家庭咨询需求卡追加在原图之后；使用“准备咨询需求”“记下咨询需求”“需求已记下”和“回到支持说明”等自然产品语言，禁止展示 DEV、synthetic、no-op、模型网关、回执、准入、同意、审计或测试数据等工程过程术语。

## 验收标准

1. UI-20 的“准备咨询需求”仅切换到 UI-21，并携带同一家庭已读主题摘要。
2. UI-21 需求草稿仅使用同一主题的可用候选时段；请求必须保留家族范围、同意、幂等与审计行为。
3. 成功反馈明确为“需求已记下”，不宣称已排期、已联系、已通知或已完成服务。
4. 自动化测试覆盖主题传递、候选时段读取、一次受保护 POST、无外部效果、失败态、返回支持说明和 UI-01 至 UI-35 全量回归。
5. 移动端复核确认动态卡位于原始 UI-21 基线之后，且动态区域无提供者、评价、价格、权益、通知、支付或工程术语。

## 浏览器复核时序说明

首次浏览器挂载以连续同步 DOM 点击测试 UI-19→UI-20→UI-21。记录显示主题目录 GET 已完成，但第二、第三个按钮在页面重绘前尚未生成，因此没有进入咨询需求页。这是浏览器演示脚本的交互时序问题，不是接口或页面功能失败；后续复核将按一次动作、一次渲染的真实用户节奏执行。
第二次逐步触发前，浏览器会话已回到未认证默认页面，临时 `fetch` 注入不再存在，因此页面显示自然加载失败态。该现象属于本地浏览器刷新后的测试会话失效；不影响前端定向测试中已验证的完整 UI-19→UI-20→UI-21 DOM 路径。最终视觉复核将以一次性、等待渲染的受控挂载完成。
最终受控浏览器挂载通过：UI-19→UI-20→UI-21 依次发生 1 次主题目录 GET、1 次候选时段 GET、1 次家庭范围需求 POST。UI-21 状态为 `SAVED`，前台文案为“咨询需求已记下。你可以继续了解，之后再决定是否需要安排。”；动态卡仅显示亲子沟通支持、支持主题、适龄参考和返回支持说明入口。提供者、资质、评价、价格、权益、通知、支付、订单和工程过程术语均未进入动态区域。
移动端视觉复核通过：原始在线咨询/预约基线完整保留，家庭咨询需求卡位于其后，留白和按钮层级清晰。动态区域仅呈现主题、适龄参考、已记下的需求反馈及返回支持说明入口；原图中的服务者、时间、问题描述、知情提示和确认预约按钮未被动态解释为已经排期、已经联系或已经完成服务。
