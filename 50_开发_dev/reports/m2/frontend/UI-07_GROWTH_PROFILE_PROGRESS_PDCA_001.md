# UI-07 成长档案与计划进展 PDCA 001

> **本轮范围**：在已对账的 `core-mine` 路由与会员中心视觉基线下，把 UI-06 的家庭私有陪跑进度连接到 UI-07 的成长档案与计划进展概览。它帮助家长重新找到正在关注的方向、目前可以回看哪些内容和下一步在哪里；不解释会员权益、积分、等级、订单、真人服务或教育结果。

## 1. Plan：家长与家庭需求

成长档案不应成为给家庭打分的个人主页。家长需要的是在一次行动、一次回顾和长期计划之间重新找到“我们现在在关注什么”“上次做了什么”“可以从哪里继续”的入口，而不是被积分、等级或剩余天数推动。家庭中心的实践资料强调，支持关系应尊重家庭的优势、观点和共同目标，并让家庭决定什么对自己重要。[1] 家庭教练研究亦将支持描述为围绕家庭价值和优先级而形成的目标、问题解决与日常惯例；这些观点只能作为本轮界面设计输入，不代表平台已提供真人教练服务或任何效果保证。[2]

| 家长问题 | UI-07 的回答 | 数据边界 |
|---|---|---|
| “我们最近在关注什么？” | 显示家庭已选择的关注方向，使用非诊断性短标题。 | 读取 UI-02 受控选择；不形成儿童画像。 |
| “之前的计划和回顾在哪里？” | 提供查看 90 天计划与家庭回顾的两个入口。 | 只导航到 UI-05/UI-08，不编辑正式计划或回顾。 |
| “会员积分、等级和订单是否说明我做得好？” | 不引用、计算或解释原图中的积分、等级、亲子币、到期日、订单或权益。 | 原图仅保留视觉结构。 |
| “是否已经有真人服务安排？” | 不展示、创建或承诺服务履约。 | 不创建 ServiceCase、Booking、消息或通知。 |

## 2. Do：最小实现设计

Core Growth 的 UI-07 卡增加 `growth_profile_progress`，仅在同一家庭已有 UI-02 关注方向时显示。字段包括：当前关注方向、计划回看入口、家庭回顾入口和温和提示。已选择 UI-05 计划或 UI-09 行动只调整可读的“可回看”说明，不作为完成度、能力、会员等级或成长结果。

UI-07 保留 `mine-member-reference-434x1124.png`，并在基线下方追加“我们的成长档案”卡。卡片提供“查看 90 天成长计划”和“查看家庭回顾”入口。它不替换、点击或解释原图中的邀请、报告、订单、客服、会员服务、积分或等级区域。

## 3. Check：验收原则

测试需证明：UI-07 使用同一家庭的关注方向；未选择方向时不伪造档案；跨家庭不泄漏；投影不含积分、等级、亲子币、会员到期、订单、权益、服务人员、Outcome 或诊断字段；两个入口只前往 UI-05/UI-08；基线保留；前台没有工程术语。移动端复核需确认动态卡位于原图下方，不覆盖会员头部、功能列表、会员服务卡或底部导航。
