# UI-11 个人成长旅程 PDCA 001

> **本轮目标**：保持“成长排行榜”原图完整可见，但将可运行内容实现为**同一家庭自己的行动历史与下一步入口**。不计算、展示或推断家庭总分、名次、跨家庭排序、同城/同班比较、百分位、称号或儿童竞争结果。

## 1. 基线阅读与替代边界

基线为 `growth-ranking-reference-450x918.png`，尺寸 450 × 918px。经两块重叠阅读后确认，上半部包含“成长排行榜”、本周/本月/同城/同班级筛选、三人奖台、家庭名称、连续打卡天数和积分；下半部延续排名列表，并包含“我的排名”、第 18 名、超过 82% 家庭、连续打卡、积分和称号。所有这些文字、数字、头像和图标均仅作为原始视觉基线，**不读取、不更新、不计算、不解释、不与任何真实家庭或儿童关联**。

动态内容只能追加到整张基线之后，标题改为“我们的成长旅程”，最多显示同一家庭已经发生的受控过程节点，例如“选择了一个关注方向”“查看过 90 天计划”“记录过一次家庭行动”“打开过家庭回顾”。这些只是动作/查看历史，不等同教育效果、能力、积分、连续性、名次、等级或荣誉。

## 2. 用户需求与最小闭环

家长不需要看到自己比其他家庭“高或低”；他们需要知道这段时间家庭已经做了哪些尝试，以及下一步可以回到哪里。UI-11 从 UI-07 成长档案进入，读取同一家庭的 UI-02、UI-04、UI-05、UI-09 和 UI-08 受控流程事件，形成按时间排序但不带分值的私人旅程。卡片只提供“查看 90 天成长计划”和“查看家庭回顾”入口。

| 用户问题 | UI-11 回答 | 明确不做 |
|---|---|---|
| “我们已经开始做什么？” | 用事件时间线回顾选择、计划查看、行动记录和回顾打开。 | 不比较其他家庭。 |
| “现在可以从哪里继续？” | 回到计划或家庭回顾。 | 不给称号、积分、连续天数或排名。 |
| “孩子做得怎么样？” | 不从单次行为推断效果、能力或结果。 | 不诊断、画像、评分或预测。 |

## 3. 验收标准

服务、集成和页面对象测试必须证明：只读取同一家庭的流程事件；不含跨家庭数据、排名、分数、百分位、同城/同班字段、称号或积分；为空时显示自然的起步提示；两个入口只导航到 UI-05/UI-08；前台不展示 DEV/synthetic/内部状态。视觉复核需证明原图完整保留，动态卡位于原图之后。

## 4. 研究依据与实现决定

家庭中心实践强调尊重家庭的观点、优势与共同目标，并让家庭决定什么对自己重要。[1] 因此，本轮把回顾的单位限定为同一家庭已经发生的受控流程事件，而不是把不同家庭、不同孩子、不同情境的行为压缩成一个比较名次。关于家长参与的研究讨论的是长期关联和复杂情境，不支持把一次或几次平台动作解释为教育效果或用于家庭间排序。[2] 这两项来源只用于指导“私有过程回看、非竞争性语言、避免因果结论”的界面设计，不作为产品效果证明。

| 设计决定 | 实现方式 |
|---|---|
| 不创建排名 | 不返回 rank、score、percentile、peer、city、class、streak、badge 或 reward 字段。 |
| 只回看同一家庭 | API 只将认证家庭的 UI-02、UI-04、UI-05、UI-09 和 UI-08 流程事件送入 UI-11 的投影构建器。 |
| 过程不是结果 | 每条时间线仅描述“选择/查看/记录/打开”等动作；不包含能力、效果、诊断、画像、预测或称号。 |
| 可继续但不自动推动 | 仅导航到 UI-05 计划和 UI-08 家庭回顾；不发送通知、不授予权益、不创建任务或服务。 |

## 5. 浏览器复核准备

已在刷新后的本地 UI-11 会话挂载同一家庭的过程事件测试投影。动态卡的预期内容仅为三项过程节点：“选择了一个家庭关注方向”“打开了本周行动”“打开了家庭回顾”，并有两个回看入口。排行榜基线的标题、筛选、奖台、名单、名次、分数、百分位和称号仍完整可见于原图；动态卡不读取或解释它们。

刷新后再次挂载测试投影。最终状态提示已调整为“成长旅程已更新。你可以回看已经走过的几步。”，不再使用与当前页面无关的泛化服务提示。

## 6. 验收结果

| 验证项 | 结果 |
|---|---|
| 平台服务单元测试 | 5/5 通过；验证无事件起步态、同家庭事件时间线、跨循环事件排除与无比较性用户字段。 |
| 控制器与流程事件定向测试 | 3 个文件、11 项测试通过；验证认证家庭流程事件可进入 UI-11 投影，同时平台回执列表仍按平台页面过滤。 |
| Web 页面对象测试 | 21/21 通过；验证旅程卡不显示开发术语、排名、积分、名次、称号或奖励，并且只可进入 UI-05/UI-08。 |
| API 全量回归 | 52 个文件、271 项测试全部通过。 |
| Web 全量回归 | 14 个文件、94 项测试全部通过；`waf.spec.ts` 的 JSDOM 导航提示为既有测试环境提示，不影响通过结果。 |
| 移动端视觉复核 | 通过；排行榜原图完整保留，家庭成长旅程卡在原图之后独立呈现，且状态提示为“成长旅程已更新。你可以回看已经走过的几步。” |

本轮结论：UI-11 的可运行层不产生、展示或计算任何比较性数据；它只帮助家长回看同一家庭已经尝试过的步骤，再回到计划或家庭回顾继续下一步。
