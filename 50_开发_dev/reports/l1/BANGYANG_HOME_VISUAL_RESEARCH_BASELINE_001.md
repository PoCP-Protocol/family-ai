# 家庭成长平台首页：视觉研究基线 001

> **唯一母版：** `pasted_file_iaWvfT_image.png`（654 × 1138 px）。
> **研究方式：** 不以“产品逻辑是否相似”判断，而按画布比例、区块顺序、文字、色彩角色、插画、图标、卡片、状态与固定导航逐项比对。

## 资产层级

1. **不可替代的原图资产：** 四口之家插画、六枚扁平功能图标、三张课程/直播人物卡、四枚 tab bar 图标。
2. **可由 CSS 严格复刻的资产：** Banner 蓝色渐变与弧形光带、圆角、白色按钮、阴影、任务胶囊、卡片分割线、文本排版、完成勾和选择状态。
3. **可由 HTML 结构复刻的资产：** 页头、欢迎区、六宫格、任务列表、推荐三卡、固定底部导航和各文案。

## 颜色研究

| 视觉对象 | 原图角色 | 执行基准 |
|---|---|---|
| 页面与卡片 | 纯白和极浅冷灰白。 | 不使用大面积渐变背景或桌面背景纹理。 |
| 主测评 Banner/首页选中 | 饱和亮蓝，右侧过渡至较浅天蓝。 | 主色仅用于 Banner、主要动作、首页选中。 |
| 文本 | 深黑蓝标题、灰蓝辅助字。 | 标题优先深黑蓝，辅助/链接用灰蓝。 |
| 图标 | 青蓝、橙、绿、橙、天蓝、珊瑚红。 | 每个入口的颜色角色固定，不能混用。 |
| 任务状态 | 绿色已完成、浅蓝描边待完成。 | 完成勾与“去完成”必须存在且位置固定。 |

## 第一轮差异基线

当前实现已完成原图同构的八区布局与原文字，但仍存在四类差异：专属插画未使用原始视觉资产；图标为临时文字/符号；推荐卡为颜色占位而非人物海报；系统栏与小程序图标未精确复刻。后续每轮只解决少量明确差异，并重新截图，不再并行扩展其他页面。
