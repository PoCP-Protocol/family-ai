# Family Legacy Migration Program V1.0

status: FORMAL_PROGRAM_DRAFT_FOR_ARCHITECT_REVIEW
date: 2026-08-10
track: V3.1_LEGACY_MIGRATION

## Architecture Conclusion

Family will not copy the old 榜样教育 systems into Family. It will preserve verified business assets, remodel family-growth meaning as Family Ontology, migrate historical data with provenance and boundaries, leave mature transaction systems behind Adapters, and proceed through Shadow, Pilot, Dual Run, and Domain Cutover until Family becomes the Family Growth System of Record.

## Strategic Boundary

Family owns:

- Family identity
- Relationships
- Consent
- Growth state as working model
- Journey
- Intervention
- Action
- Event
- Outcome
- Timeline
- AI context

External systems retain:

- CRM lead, opportunity, sales, and commercial follow-up
- LMS class and teaching operations
- Order, payment, refund, invoice, and transaction ledger
- Live delivery technology
- Support and community channel operations

## Migration Model

This program uses Semantic Migration:

```text
Legacy Systems
-> Raw Landing Zone
-> Migration Staging
-> Identity Resolution
-> Semantic Mapping
-> Data Quality / Consent / Safety Validation
-> Quarantine / Human Review
-> Migration Named Actions
-> Family Canonical Ontology
```

## Routes

The 55 legacy assets in the migration matrix are grouped into five routes:

- TRANSFORM: customer, parent, child, relationship, assessment, profile/tag, task, check-in, growth report, AI diagnosis.
- MIGRATE: historical growth data, assessment records, check-ins, service records, growth reports, journey history.
- INTEGRATE: CRM, LMS, order, payment, live, support, community channels.
- RETAIN_AND_REORGANIZE: courses, camps, 21-day challenge, 90-day journey, advisors, assistants, experts, SOPs.
- RETIRE: leaderboard and family total score.

## Red Lines

- Legacy label -> Fact is forbidden.
- Legacy score -> Growth State is forbidden.
- Legacy AI report -> Diagnosis is forbidden.
- Legacy check-in -> Outcome is forbidden.
- Course completion -> growth improvement is forbidden.
- Historical customer relationship -> Consent is forbidden.
- Legacy group membership -> FamilyRelationship is forbidden.
- Same phone number -> automatic family merge is forbidden.
- Legacy minor data -> AI training permission is forbidden.
