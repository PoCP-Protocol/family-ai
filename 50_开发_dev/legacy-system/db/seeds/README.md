```text
REFERENCE_IMPLEMENTATION = TRUE

```

FELS-0 defines seed contracts only. FELS-1+ may add executable seed scripts:

- `pnpm legacy:seed:small`
- `pnpm legacy:seed:medium`
- `pnpm legacy:seed:dirty`

Datasets are specified in `../synthetic/SYNTHETIC_DATA_SPEC.md`.
