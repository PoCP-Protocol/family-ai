## 阶段门

### Gate 1：来源登记

- 来源必须可追溯；
- DOI/官方URL必须核验；
- 写入 `library/verified_sources.yaml`；
- 未登记来源不能作为 `external_verified`。

### Gate 2：理论卡

- 有明确原始理论或权威综述；
- 写出核心主张、边界和中国情境疑问；
- `defines` 必须指向真实构念卡；
- 不把商业IP主张写成已验证理论。

### Gate 3：构念卡

- 有操作性定义；
- 有理论根；
- 有明确变化方向；
- 至少连接一个测量通道；
- 标明代理指标风险。

### Gate 4：测量卡

- 明确测量渠道和工具状态；
- 写明信效度、家庭可行性和隐私风险；
- 涉未成年人必须有单独Consent和数据处理规则；
- 不把打卡、课程完成率或家长自评直接当作Outcome。

### Gate 5：方法卡

- 必须有理论根和目标构念；
- 必须有步骤、剂量、适用年龄、禁忌、失败模式；
- 中高风险场景必须声明 `human_requirement`；
- 微动作效果不得超过整体项目证据强度。

### Gate 6：实践项目卡

- 仅登记有完整实施结构的外部项目；
- 记录年龄、剂量、实施者要求和独立研究；
- 明确版权、商标、认证和商业授权；
- 未经授权不得复刻完整项目。

### Gate 7：Family产品适配

只有前六道门通过后，才允许形成产品设计输入：

```text
家庭场景 → 构念识别 → 低风险方法 → Consent/Policy检查 → Named Action → Outcome复盘
```

产品适配不是复制课程、品牌、金句或工具，而是迁移经过验证的抽象结构，并重新定义自己的内容、测量和评估。
