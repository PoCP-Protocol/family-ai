# 02｜主张与证据状态表

本文件用于防止资料中的愿景、判断、事实和假设混用。

状态定义：

| 状态 | 含义 | 使用方式 |
|---|---|---|
| 已有规格收敛 | 已被 `10_规格_spec/` 明确吸收并转成实施边界 | 可作为产品/研发依据 |
| 战略判断 | 材料反复出现，逻辑上成立，但仍需业务验证 | 可用于方向讨论，不可当成已证明事实 |
| 待验证假设 | 需要运营数据、研究证据或试点结果支持 | 进入研究/试点，不直接承诺 |
| 存在张力 | 材料之间或价值边界上存在冲突 | 需要决策或重新表述 |
| 禁止/需修正 | 与 Family 规格红线冲突 | 不得按原样进入产品 |

## 十一、优先进入研究/验证的主张

建议优先验证以下 12 条，因为它们直接决定产品和商业路径：

1. U-02：用户真正付费原因是否是孩子改变和家庭关系改善。
2. U-05：首发高频问题到底是哪一个。
3. P-01：测评 → 21 天 → 90 天 → 年度会员漏斗是否成立。
4. P-04：21 天是否能产生可见小改变。
5. G-01：增长是否能逐步降低对投流依赖。
6. G-04：真实改变是否能带来主动分享。
7. D-01：交付 SOP 化是否能降低名师依赖。
8. DATA-01：家庭成长数据库是否真的提升交付和留存。
9. AI-01：AI 进入闭环后是否提高完成率、反馈质量或顾问效率。
10. FIN-01：收入结构能否从课程向会员/订阅迁移。
11. RISK-03：高风险场景 Human Gate 是否可操作。
12. RISK-06：成功案例传播是否能兼顾转化与合规。

## 十二、当前结论

现有资料中的战略方向已经被规格包较好地收敛，但商业效果、增长效率、数据壁垒、AI 提效、资本估值等主张仍处于待验证状态。

因此，下一阶段资料工作不应继续扩写 PPT，而应转向四类结构化资产：

1. Current State Blueprint：现有产品、服务、SOP、系统、数据、Owner。
2. Evidence Registry：关键商业和教育科学主张的证据库。
3. Vertical Slice Spec：第一条 Profile → Outcome 闭环的开发级规格。
4. Pilot Measurement Plan：30 个家庭试点的指标、采集、风险和复盘方法。
