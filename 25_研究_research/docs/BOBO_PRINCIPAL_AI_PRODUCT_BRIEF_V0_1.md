# 波波校长 AI 化产品 Brief V0.1

日期: 2026-08-10

定位: 以波波校长形象为用户可感知入口,把家庭教育经验、家长陪练、训练营陪跑和内容栏目做成一个能马上使用的 AI人产品,而不是仿真人,也不是先做抽象治理平台。

---

## 1. 产品一句话

**波波校长 AI人是家长身边的家庭成长校长: 能听懂当下冲突,把话说明白,把今晚要做的一件事落下来,并陪家长走完 21 天。**

---

## 2. 第一版用户入口

| 入口 | 用户看到什么 | 第一版必须能做 |
|---|---|---|
| 问波波校长 | 一个带波波校长形象的对话入口 | 家长输入困扰后,输出承接、判断、今晚行动 |
| 今晚怎么说 | 亲子沟通话术改写工具 | 把家长原话改成温和版、边界版、青春期版 |
| 21 天陪跑 | 每天一张行动卡 | 给今日任务、提醒话术、晚间复盘问题 |
| 校长一分钟 | 内容栏目 | 高频痛点短视频/音频脚本,一个场景一个动作 |
| 顾问助手 | 内部助教/顾问工作台 | 摘要家庭近况,生成下一次沟通提纲 |

---

## 3. MVP 不做什么

1. 不先做复杂后台。
2. 不先做全量知识库。
3. 不先做大而全 Agent 平台。
4. 不承诺疗效和改变结果。
5. 不把用户输入直接写成 Family 核心事实。

MVP 先证明三件事: 家长愿不愿意问、回答是否像波波校长、家长会不会执行今晚这一小步。

---

## 4. 波波校长 AI人改造

| 组件 | AI人表达 |
|---|---|
| 视觉 | 头像、半身数字人、栏目封面、训练营主持卡片 |
| 声音 | 可选语音播报,先用文本版验证内容有效性 |
| 人格 | 温暖、直接、看见父母、看见孩子、给具体下一步 |
| 内容 | “校长一分钟”“今晚怎么说”“家长第二成长”“21 天陪跑” |
| 交互 | 问答、改写、行动卡、复盘、顾问摘要 |

---

## 5. 核心回答模板

```json
{
  "opening": "先像波波校长一样接住家长的一句话",
  "what_i_hear": "复述家长困扰,不急着评判",
  "not_the_label": "提醒不要给孩子或父母贴标签",
  "try_tonight": "今晚只做一件小事",
  "say_it_like_this": "给一句可直接说出口的话",
  "look_for": "观察一个信号",
  "next_check_in": "明天或今晚复盘问什么"
}
```

## 6. 第一批场景

| 场景 | 产品能力 | 示例输出方向 |
|---|---|---|
| 孩子沉迷手机 | 问波波校长 + 家庭小会 | 先区分学习工具和娱乐入口,共创一个小规则 |
| 初中孩子顶嘴 | 今晚怎么说 | 从讲道理改成复述和低设防提问 |
| 作业拖拉 | 今晚怎么说 + 21 天陪跑 | 把催促改成任务拆分和结束仪式 |
| 家长吼完后悔 | 家长第二成长 | 先修复关系,再找触发点 |
| 孩子不想上学 | 问波波校长 | 降压、澄清事实、必要时转人工 |
| 二孩关注不均 | 家庭小会 | 给老大一个固定短独处时间 |

## 7. 7 天产品原型节奏

| Day | 产物 |
|---|---|
| D1 | 波波校长 AI 首页草图: 问答入口、话术改写、21 天陪跑 |
| D2 | 20 条高频场景样本和标准回答 |
| D3 | 对话 Prompt + JSON 输出 schema |
| D4 | 话术改写工具原型 |
| D5 | 21 天行动卡原型 |
| D6 | 顾问摘要原型 |
| D7 | 10 个真实家长场景内测,记录是否愿意继续用 |

---

## 8. 成功信号

1. 家长愿意把真实困扰输入给波波校长 AI。
2. 回答被评价为“像一个懂家庭教育的人在说话”,不是客服话术。
3. 至少 50% 内测家长愿意执行“今晚一件小事”。
4. 家长第二天愿意回来复盘。
5. 顾问觉得摘要能节省服务准备时间。

---

## 9. 立即进入工程的产品切片

第一刀不做完整平台,只做一个可演示页面:

```text
波波校长 AI 首页
-> 输入家庭困扰
-> 生成结构化回答
-> 一键切换“今晚怎么说”
-> 生成 1 张今日行动卡
-> 保存复盘文本
```

这个切片足够展示产品感,也能为后续训练样本和真实用户反馈提供闭环。
